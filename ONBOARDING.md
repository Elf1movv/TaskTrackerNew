# MyTracker — быстрое восстановление контекста

Если ты читаешь это по ссылке, без доступа к самому репозиторию —
короткая шпаргалка, чтобы сориентироваться. **Полная версия — не
здесь, а в самом репозитории**, три файла в таком порядке:
`CLAUDE.md` → `PROJECT_BRAIN.md` → `LEARNING.md`.

## Что это

**MyTracker** — личный трекер задач/целей/привычек. Продакшен:
https://mytracker.space. Код: `git@github.com:Elf1movv/TaskTrackerNew.git`
(GitHub: `Elf1movv/TaskTrackerNew`).

Владелец — полный новичок в программировании, строит это как свой
первый реальный проект, учась по ходу дела. Если ты — AI-ассистент,
веди себя как терпеливый наставник: объясняй термины сразу простым
языком, не сыпь жаргоном без объяснения.

## Стек одной строкой

React + TypeScript + Vite (фронтенд, Feature-Sliced Design) · Node +
Express + Prisma + PostgreSQL (бэкенд) · Better Auth (своя
авторизация, email+пароль) · Resend (письма) · свой VPS (не
Vercel/Railway) · Docker + GitHub Actions (CI/CD, пуш в `main` = автодеплой).

## Первым делом на новом месте

1. Склонировать репозиторий — там `CLAUDE.md` (как работать),
   `PROJECT_BRAIN.md` (полный контекст + что делать при потере
   доступа к чему угодно — серверу, домену, GitHub, БД), `LEARNING.md`
   (журнал решений)
2. Если открываешь в Claude Code — `CLAUDE.md` подхватится сам
   автоматически, ничего специально просить не нужно
3. Если нужно вообще без AI — `PROJECT_BRAIN.md`, раздел 4, объясняет,
   как посмотреть код/базу/логи сервера напрямую (VS Code + Remote-SSH,
   Prisma Studio, `docker compose logs`)

## Если это конкретно "потерял доступ к предыдущему чату"

Это не потеря данных — весь код в GitHub, приложение и база живут на
VPS независимо от того, какой чат/аккаунт Claude сейчас используется.
Единственное, что не переезжает — локальная память ассистента на
старом компьютере. Она и не должна быть нужна: всё важное на постоянной
основе уже записано в `CLAUDE.md`/`PROJECT_BRAIN.md`/`LEARNING.md`/
`docs/` внутри самого репозитория.

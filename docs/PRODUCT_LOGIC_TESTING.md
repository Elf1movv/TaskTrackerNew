## Проверка владельцем на стенде

Пользоваться https://test.mytracker.space со своим отдельным аккаунтом.
Технические проверки выполняет ассистент на служебном аккаунте; владелец
оценивает понятность действий и удобство на своих примерах.

| Где и что сделать | Ожидаемый результат |
|---|---|
| Сегодня → «Добавить заметку»: «Купить батарейки», длинное описание. Раскрыть, отредактировать, отправить в архив и восстановить | Текст сохраняется, блок растёт по высоте. Заметка не становится задачей или календарным планом |
| Создать заметку с будущей датой, открыть «Предстоящие» | Дата задаёт начало показа; до неё запись находится в предстоящих, не занимает время в календаре |
| Задачи → добавить «Написать заказчику» со сроком; затем «Запланировать» два интервала | Сам срок не создаёт рабочий блок. Два интервала ссылаются на одну задачу |
| Календарь → выбрать день, создать самостоятельную встречу, затем план без времени | Выбранная дата уже установлена. Встреча не появляется в задачах, план без времени виден над шкалой |
| Перетащить один интервал на другой день, растянуть; перенести в «Отложено» и вернуть | Срок задачи и второй интервал не меняются. Перенос сохраняет длительность, растягивание меняет её. Дубликатов нет |
| Отметить связанную задачу выполненной из календаря; открыть Задачи → «Готово» | Одна общая отметка выполнения, история по 10. Будущие интервалы остаются приглушёнными до явной очистки |
| Привязать задачу к цели, выполнить её, затем отдельно нажать «Цель достигнута» | Прогресс обновляется; достижение подтверждается отдельно. Достигнутую цель можно вернуть в активные |
| У плана нажать «Напомнить», задать 30 минут до начала, перенести план и отложить | Час сигнала следует за планом; в «Отложено» относительное напоминание приостановлено |
| Сегодня → «Добавить блок» привычек, оставить пустым; обновить страницу | Блок сразу виден и сохраняется без первой привычки |

Повторить самые частые действия на своём телефоне. Отдельно оценить:
понятно ли, где создавать заметку, задачу и план; не перегружается ли
главная при планировании недели; хватает ли описаний и переходов.
Сохраняется известное замечание к тесной мобильной шапке привычек
(BACKLOG, 2026-10-02); проверки ширины заметок его не закрывают.

В новом аккаунте нет прежних записей, поэтому экран их разбора обычно
не появится. Его техническая проверка выполнена на искусственных старых
записях служебного аккаунта. Для пользовательской оценки перехода нужно
отдельно подготовить такие примеры, не копируя production-данные.

Для сообщения о баге достаточно: раздел → действия → ожидаемый результат
→ фактический результат, устройство и при возможности снимок экрана.

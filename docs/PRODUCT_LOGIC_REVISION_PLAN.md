# Независимые разделы — план второй итерации, 2026-10-10

Владелец подтвердил вариант 1: цели как на production с собственными
подцелями. Заметки, общие задачи и календарные планы самостоятельны.
Недельное расписание не заполняет задачи. Работы выполняются в
feat/product-logic-redesign; main требует отдельного разрешения.

## Реализация

1. Заметки: полное скрытие/раскрытие описания, выполнение и отмена
   галочкой (зачёркивание без автоматического архива), удаление с
   подтверждением во всех вкладках, перетаскивание за ручку мышью/касанием.
   Ручной порядок сохраняется после перезагрузки во всех вкладках;
   дата определяет вкладку, а не принудительную сортировку.
   Архив/восстановление остаются отдельными действиями. Старые заметки
   получают completed=false без изменения содержания.
2. Цели: вернуть собственные milestones и прогресс по ним, формы
   добавления/редактирования/удаления/перестановки подцелей. Убрать
   привязку общих задач и отдельное ручное «достижение» цели.
3. Задачи/календарь: убрать выбор исходной задачи в плане и действия
   планирования задачи. Даты задач остаются сроками. Планы имеют
   собственные название, описание и выполнение. Сохраняются выбранная
   дата при создании, переносы, изменение длительности, «Без времени»
   и карман «Отложено» с возвратом в расписание.
4. Убрать связанные напоминания из новых форм; обычные напоминания
   и привычки сохраняют существующее поведение. Сроки целей остаются
   существующими календарными маркерами, не создающими планов/задач.
5. Данные: перед стендом резервная копия; опубликованные миграции
   не переписываются. Новая миграция сохраняет содержание связанных
   планов перед отвязкой. Подцели больше не предлагаются к преобразованию
   в общие задачи. Старые неоднозначные Task остаются в разборе с выбором
   ровно одного назначения; выбор «Задача» не создаёт план.
   Уже выполненные экспериментальные преобразования проверяются отдельно
   по журналу, без потери содержания и без молчаливого удаления записей.
6. Проверки: frontend/backend typecheck, lint, fsd-lint, оба набора тестов,
   сборка, настоящий браузер (desktop/mobile), тесты API независимости,
   старых данных, изоляции пользователей, конфликтов версий. Тесты с
   очисткой таблиц запускаются только в локальной тестовой БД.
7. Обновить requirements/ARCHITECTURE/BACKLOG/LEARNING и состояние стенда.
   После проверок собрать отдельный staging-образ, установить на
   test.mytracker.space, проверить там на отдельном QA-аккаунте.

## Границы

История выполненных задач по 10 и оформление фильтров срока сохраняются.
Привычки, самостоятельные напоминания и production не переделываются.
Это замена связей в экспериментальной версии, а не полный откат ветки.
Старая схема и журнал перехода сохраняются для восстановления/аудита.

## Локальный результат 2026-11-02

Код и миграция реализованы; 118 frontend, 83 backend теста, 24 браузерных
сценария пройдены. У единственной экспериментальной связанной задачи
сохраняется место в Tasks и всё содержание; связь снимается, цель остаётся.
Владельцу предложен этот бережный вариант, альтернативного указания не было.
Дальше — резервная копия стенда, сравнение контрольных сумм, установка и
проверка через публичный HTTPS. Публикация в main требует отдельного решения.

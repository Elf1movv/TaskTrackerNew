## Замеры

Локальная копия (`run-local.sh`), 6 привычек с историей 3–10 месяцев,
экран 390 px, первый запуск без кеша и без копии на телефоне.

| | Быстрый ПК | «Слабый телефон» (процессор ×4 медленнее, 1,6 Мбит/с, задержка 150 мс) |
|---|---|---|
| Запуск до готового экрана «Привычки» | 0,5 с | 3,3 с (из них код 417 КБ — 2,4 с) |

Повторный запуск в разы быстрее — код уже лежит на телефоне (service worker,

## Итерация «Скорость» (ждёт решения владельца)

1. Код по экранам (`React.lazy`), графики Recharts — отдельно и только на
   компьютере (советы 11, 22).
2. Шрифты: убрать JetBrains Mono, Manrope хранить у себя, только нужные
   начертания, кириллица + латиница, `preload` (29).
3. Расчёты привычек через `Set` (26).
4. Таймауты на письма и push (12).
5. Лог медленных запросов сервера > 500 мс (18).
6. Замер «слабого телефона» и числа запросов при запуске в `run-local.sh`
   (3, 31).

Цель — первый запуск на слабом телефоне заметно быстрее 3,3 с, «Год» —
меньше 100 мс. Следующая итерация — кеш данных на телефоне (SWR + ETag) с
серыми заглушками там, где данных ещё нет (1, уже в BACKLOG).

## После итерации «Скорость» (2026-11-18, ветка `feat/speed`)

Тот же скрипт, те же 6 привычек, по два прогона:

| | До | После |
|---|---|---|
| Запуск на «слабом телефоне» до экрана «Привычки» | 3,45 с | **2,55–2,59 с** |
| Код при запуске (сжатый) | 417 КБ одним файлом | **270 КБ** + файл открытого экрана |
| Графики Recharts на телефоне | скачивались (≈100 КБ) | **не скачиваются** |
| Переключение на «Год», слабый телефон | 145–200 мс | **96–99 мс** |
| Шрифты | Google, 3 сервера по очереди, + неиспользуемый JetBrains Mono | свои, 2 файла 14 + 24 КБ |
| Повторные запросы `/api` при запуске | не проверяли | **нет** (10–11 запросов, все разные) |
| Обращения к чужим серверам | Google Fonts | **нет** |

Что сделано:
- экраны грузятся отдельно (`React.lazy` в `router.tsx`), графики — отдельно и только на компьютере;
- плагин `listAllAssets` (`vite.config.ts`) вписывает все файлы в `<meta name="app-assets">`, поэтому копия на телефоне хранит все экраны: 27 из 27, без сети переходы работают;
- Manrope хранится у себя (`src/styles/fonts.css`);
- `hasCompletion` (`Set`) и быстрый `formatDateKey`;
- письма и push ждут не дольше 10 с;
- лог `slow request` для запросов дольше 500 мс;
- `scripts/qa/perf.mjs` в `run-local.sh`.

Попутно: `useIsMobile` знал ответ только после первой отрисовки. Телефон на долю секунды рисовал компьютерный вид, и графики начинали скачиваться. Теперь ответ известен сразу.

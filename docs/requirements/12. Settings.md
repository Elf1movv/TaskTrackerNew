# 12. Settings

Панель настроек — кнопка-шестерёнка, закреплённая в правом верхнем углу
на каждой защищённой странице (десктоп и мобильные ширины одинаково),
открывающая выезжающую справа панель (`Sheet`). Наверху — три вкладки:
«Аккаунт», «Внешний вид», «Уведомления» (с 2026-11-12). Внизу — кнопки
«Установить приложение» (если браузер умеет), «Пройти знакомство заново» и
«Выйти». Это единственное место в приложении, где можно сменить язык
интерфейса, тему оформления, включить уведомления или выйти из аккаунта;
сами механизмы описаны отдельно — [07. Localization](./07.%20Localization.md),
[08. Theme](./08.%20Theme.md), [13. Reminders](./13.%20Reminders.md) (13.05),
[15. PWA](./15.%20PWA.md).

Смена пароля (экран "Аккаунт") вызывает существующий эндпоинт Better
Auth (`POST /api/auth/change-password`) — сам эндпоинт и общие правила
пароля (длина, буква+цифра) описаны в
[09.01. Account Access-BACKEND](./09.%20Authentication/09.01.%20Account%20Access-BACKEND.md),
"Правила пароля", не дублируются здесь.

- [12.01. Settings Panel-FRONTEND](./12.%20Settings/12.01.%20Settings%20Panel-FRONTEND.md)
  — кнопка, `Sheet`, вкладки (Аккаунт / Внешний вид / Уведомления),
  кнопки внизу, вкладка "Аккаунт" с инлайн-формой смены пароля, вкладка
  "Внешний вид" (переключатели языка/темы)
  (без BACKEND — своего серверного метода у панели нет, использует
  существующий `POST /api/auth/change-password`, см. выше)

# 12. Settings

Панель настроек аккаунта — кнопка-шестерёнка, закреплённая в правом
верхнем углу на каждой защищённой странице (десктоп и мобильные ширины
одинаково), открывающая выезжающую справа панель (`Sheet`). Сейчас в
панели одна секция, "Аккаунт" — почта (только для чтения) и смена
пароля, — но панель спроектирована так, чтобы рядом можно было
смонтировать другие секции в будущем. Переключатели темы и языка в неё
не перенесены, остаются в сайдбаре (см.
[07. Localization](./07.%20Localization.md),
[08. Theme](./08.%20Theme.md)).

Смена пароля вызывает существующий эндпоинт Better Auth
(`POST /api/auth/change-password`) — сам эндпоинт и общие правила
пароля (длина, буква+цифра) описаны в
[09.01. Account Access-BACKEND](./09.%20Authentication/09.01.%20Account%20Access-BACKEND.md),
"Правила пароля", не дублируются здесь.

- [12.01. Settings Panel-FRONTEND](./12.%20Settings/12.01.%20Settings%20Panel-FRONTEND.md)
  — кнопка, `Sheet`, секция "Аккаунт", инлайн-форма смены пароля
  (без BACKEND — своего серверного метода у панели нет, использует
  существующий `POST /api/auth/change-password`, см. выше)

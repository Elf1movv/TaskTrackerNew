# 12. Settings

Панель настроек — кнопка-шестерёнка, закреплённая в правом верхнем углу
на каждой защищённой странице (десктоп и мобильные ширины одинаково),
открывающая выезжающую справа панель (`Sheet`) с двухуровневым меню.
Корневой экран — список из двух навигируемых строк ("Аккаунт", "Внешний
вид") и кнопка "Выйти"; клик по строке переводит на соответствующий
экран, стрелка назад в шапке возвращает к списку. Это единственное
место в приложении, где можно сменить язык интерфейса, тему оформления
или выйти из аккаунта — раньше эти элементы жили в подвале десктопного
сайдбара и были недоступны на мобильных ширинах (см.
[06. Navigation](./06.%20Navigation.md)); сами механизмы языка и темы
по-прежнему описаны отдельно — [07. Localization](./07.%20Localization.md),
[08. Theme](./08.%20Theme.md).

Смена пароля (экран "Аккаунт") вызывает существующий эндпоинт Better
Auth (`POST /api/auth/change-password`) — сам эндпоинт и общие правила
пароля (длина, буква+цифра) описаны в
[09.01. Account Access-BACKEND](./09.%20Authentication/09.01.%20Account%20Access-BACKEND.md),
"Правила пароля", не дублируются здесь.

- [12.01. Settings Panel-FRONTEND](./12.%20Settings/12.01.%20Settings%20Panel-FRONTEND.md)
  — кнопка, `Sheet`, корневое меню (Аккаунт / Внешний вид / Выйти),
  экран "Аккаунт" с инлайн-формой смены пароля, экран "Внешний вид"
  (переключатели языка/темы)
  (без BACKEND — своего серверного метода у панели нет, использует
  существующий `POST /api/auth/change-password`, см. выше)

# 12.01. Settings Panel [Frontend]

# Описание

Кнопка-шестерёнка, закреплённая в правом верхнем углу каждой защищённой
страницы, открывающая выезжающую справа панель (`Sheet`) с заголовком
"Настройки". Панель содержит одну секцию, "Аккаунт" — почта
пользователя (только для чтения) и инлайн-форма смены пароля.
Спроектирована для роста — секция "Аккаунт" не единственная, которая
когда-либо будет в этой панели, просто пока единственная, которая есть.

# Где находится (файлы)

- `src/widgets/settings-panel/ui/SettingsPanel.tsx` — кнопка-шестерёнка,
  `Sheet`/`SheetTrigger`/`SheetContent`/`SheetHeader`/`SheetTitle`
- `src/widgets/settings-panel/ui/components/AccountSection.tsx` —
  секция "Аккаунт": почта, форма смены пароля
- `src/widgets/settings-panel/index.ts` — публичный API виджета
  (обязателен по правилу FSD `fsd/no-public-api-sidestep`)
- `src/shared/ui/sheet.tsx` — примитив `Sheet` (обёртка над
  `@radix-ui/react-dialog`) — первое реальное использование `Sheet` в
  проекте
- `src/shared/ui/password-input.tsx` — `PasswordInput`, поле пароля с
  переключателем видимости
- `src/shared/ui/password-requirements-hint.tsx` —
  `PasswordRequirementsHint`, общий компонент с формой регистрации (см.
  [09.01. Account Access-FRONTEND](../09.%20Authentication/09.01.%20Account%20Access-FRONTEND.md))
- `src/shared/lib/auth/authClient.ts` / `src/shared/lib/auth/index.ts` —
  экспорт `changePassword`
- `src/app/layouts/RootLayout.tsx` — точка монтирования
  (`<SettingsPanel email={session.user.email} />`)
- `src/shared/lib/i18n/dictionaries/en.ts` / `ru.ts` — ключи
  `settings.*`

# Функциональные требования

## Кнопка и панель

1. Кнопка-шестерёнка (иконка `Settings` из `lucide-react`) зафиксирована
   в правом верхнем углу (`fixed top-4 right-4 md:top-6 md:right-6`) —
   смонтирована в `RootLayout`, то есть видна на каждом маршруте,
   защищённом сессией (`/today`, `/tasks`, `/goals`, `/calendar`), но не
   на `/login`/`/register`/`/forgot-password`/`/reset-password`, которые
   рендерятся вне `RootLayout` (см.
   [09.01. Account Access-FRONTEND](../09.%20Authentication/09.01.%20Account%20Access-FRONTEND.md))
2. Клик по кнопке открывает `Sheet` со стороны `right` — затемняющий
   оверлей и панель шириной 3/4 экрана на мобильных ширинах,
   `sm:max-w-sm` на десктопе, с анимацией выезда/задвигания
   (`slide-in-from-right`/`slide-out-to-right`)
3. Заголовок панели — "Настройки" (`settings.title`); закрывается
   кликом по кнопке `×` в правом верхнем углу панели, кликом по оверлею
   вне панели или клавишей Escape — стандартное поведение
   `@radix-ui/react-dialog`, на котором построен `Sheet`, своей логики
   закрытия в проекте нет

## Секция "Аккаунт" (`AccountSection`)

4. Заголовок секции — "Аккаунт" (`settings.account.title`)
5. Почта — только для чтения, показывает значение пропа `email`
   (`session.user.email`, переданное из `RootLayout`) — секция не
   делает собственного запроса за данными пользователя
6. Пароль показан замаскированным (`••••••••` — литеральные точки, не
   настоящие символы: сервер никогда не присылает клиенту пароль в
   открытом виде, см.
   [09.01. Account Access-BACKEND](../09.%20Authentication/09.01.%20Account%20Access-BACKEND.md),
   "Схема данных") рядом с кнопкой "Изменить"
   (`settings.account.changePassword`)
7. Клик "Изменить" разворачивает инлайн-форму на месте замаскированной
   строки (`isChanging` в состоянии `AccountSection`) — вместо неё
   появляются поля "Текущий пароль", "Новый пароль", чекбокс "Выйти из
   остальных устройств" и кнопки "Сохранить"/"Отмена"

## Форма смены пароля

8. Оба поля пароля — `PasswordInput`: поле ввода плюс кнопка-иконка
   (глаз/перечёркнутый глаз) справа внутри поля, переключающая `type`
   между `"password"`/`"text"` только для этого конкретного поля —
   раскрывает то, что сейчас набрано в нём, а не хранимый пароль
   (сервер его не присылает, см. п. 6)
9. "Текущий пароль" — автофокус при открытии формы, без ограничения
   длины и без `PasswordRequirementsHint` (это уже существующий пароль,
   а не новый, который нужно проверять на соответствие правилам)
10. "Новый пароль" — `maxLength={MAX_PASSWORD_LENGTH}` (128), под полем
    — `PasswordRequirementsHint`, тот же компонент и те же два правила
    (длина 8–128, буква и цифра), что на регистрации (см.
    `09.01. Account Access-FRONTEND.md`, п. 5)
11. Чекбокс "Выйти из остальных устройств" (`revokeOtherSessions`) — не
    отмечен по умолчанию
12. Кнопка "Сохранить" задизейблена, пока `'currentPassword'` пуст или
    `meetsPasswordRequirements('newPassword')` не возвращает `true`, а
    также пока идёт отправка (`isSubmitting`)
13. Отправка (`handleSubmit`):
    1. Дополнительно не выполняется, если условия п. 12 не выполнены
       (защита сверх задизейбленной кнопки)
    2. Вызывает `changePassword({ currentPassword, newPassword,
       revokeOtherSessions })` (`authClient.changePassword`, см.
       [09.01. Account Access-BACKEND](../09.%20Authentication/09.01.%20Account%20Access-BACKEND.md),
       `POST /api/auth/change-password`)
    3. При успехе — `toast.success(t("settings.account.success"))`
       ("Пароль изменён"), форма сворачивается обратно к
       замаскированному виду, поля `currentPassword`/`newPassword`/
       `revokeOtherSessions` сбрасываются
    4. При ошибке — `toast.error(translateAuthError(error, t,
       "auth.error.generic"))`, тот же переводчик кодов ошибок, что у
       регистрации и входа (неверный текущий пароль → `error.code =
       "INVALID_PASSWORD"` → `auth.error.wrongCurrentPassword`, "Неверный
       текущий пароль."); форма остаётся открытой, введённые значения не
       теряются
14. Кнопка "Отмена" вызывает тот же сброс формы (`resetForm`), что и
    успешная отправка — сворачивает форму обратно к замаскированному
    виду, ничего не отправляя на сервер

# Известные ограничения

1. Секция "Аккаунт" — единственная в панели; компонент спроектирован
   для роста (`SettingsPanel.tsx:6-8` — комментарий про несколько
   `<...Section />` в будущем), но пока ничего, кроме неё, не
   смонтировано
2. Почта и имя пользователя — только для чтения; изменить их через эту
   панель нельзя, единственное реальное действие в ней — смена пароля
   (и опционально выход из остальных устройств заодно с ней)
3. Переключатели темы и языка в панель не перенесены, остаются в
   сайдбаре (см.
   [07.01. Language Toggle-FRONTEND](../07.%20Localization/07.01.%20Language%20Toggle-FRONTEND.md),
   [08.01. Theme Toggle-FRONTEND](../08.%20Theme/08.01.%20Theme%20Toggle-FRONTEND.md))

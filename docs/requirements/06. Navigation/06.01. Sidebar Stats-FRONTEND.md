# 06.01. Sidebar Stats [Frontend]

# Описание

Левый сайдбар с навигацией между страницами и тремя счётчиками. Это
**глобальный** элемент интерфейса — виден на всех страницах приложения
одновременно, не только на Today, несмотря на то, что все три счётчика
показывают именно "на сегодня".

# Где находится (файлы)

- `src/widgets/navigation/ui/SidebarNav.tsx` — сам сайдбар и вычисление
  счётчиков
- `src/widgets/navigation/model/navItems.ts` — список пунктов меню

# Функциональные требования

1. Сайдбар скрыт на мобильных экранах (`hidden md:flex`) — виден только
   от планшетного размера и шире
2. Пункты меню — ссылки на Today/Tasks/Goals/Habits/Calendar, активный
   пункт подсвечен по текущему маршруту
3. Счётчик `'Tasks done'` — считает **только задачи с сегодняшним
   `'dueDate'`** (тот же фильтр `selectTodayTasks`, что использует
   Today), в формате "выполнено / всего". Задачи без срока или с другим
   сроком в этот счётчик не входят
4. Счётчик `'Habits'` — "количество привычек, отмеченных сегодня /
   общее количество привычек" — не связан с streak (серией дней подряд),
   считает только сегодняшний день
5. Счётчик `'Active goals'` — **вводит в заблуждение по названию**: это
   просто общее количество целей (`goals.length`), без какой-либо
   фильтрации по прогрессу. Цель со `'progress' = 100` тоже учитывается
   в этом числе
6. Все три счётчика пересчитываются реактивно при любом изменении
   соответствующих данных — отдельного запроса к серверу для них нет,
   используются те же `tasks`/`goals`/`habits` из общих провайдеров

# 06.01. Sidebar Stats [Frontend]

# Описание

Левый сайдбар с навигацией между страницами, тремя счётчиками и двумя
переключателями (язык интерфейса, тема оформления). Это **глобальный**
элемент интерфейса — виден на всех страницах приложения одновременно, не
только на Today, несмотря на то, что все три счётчика показывают именно
"на сегодня".

# Где находится (файлы)

- `src/widgets/navigation/ui/SidebarNav.tsx` — сам сайдбар, вычисление
  счётчиков, подпись-название приложения
- `src/widgets/navigation/model/navItems.ts` — список пунктов меню
  (`labelKey` — ключ словаря i18n, не строка)
- `src/widgets/navigation/ui/MobileNav.tsx` — тот же список пунктов меню
  в нижней панели на мобильных экранах
- `src/shared/ui/language-toggle.tsx` — переключатель EN/RU
- `src/shared/ui/theme-toggle.tsx` — переключатель светлой/тёмной темы
- `src/shared/lib/i18n` — см.
  [07. Localization](../../07.%20Localization.md)

# Функциональные требования

1. Сайдбар скрыт на мобильных экранах (`hidden md:flex`) — виден только
   от планшетного размера и шире. На мобильных вместо него —
   `MobileNav`, нижняя панель с теми же пунктами меню (без счётчиков и
   без переключателей языка/темы)
2. В шапке сайдбара — статичная надпись `"MyTracker"` (название
   приложения, `SidebarNav.tsx:38`) и текущие месяц/год. Надпись не
   переведена на RU — как и категории, это не текст интерфейса, а
   название бренда (см. `07. Localization.md`)
3. Пункты меню — ссылки на Today/Tasks/Goals/Calendar (`NAV_ITEMS`,
   `navItems.ts`), активный пункт подсвечен по текущему маршруту.
   Привычки (Habits) не вынесены в отдельный пункт меню — они
   отображаются на странице Today (см. `05.01. Today
   Dashboard-FRONTEND.md`), отдельного маршрута `/habits` в приложении
   нет
4. Счётчик `'Tasks done'` — считает **только задачи с сегодняшним
   `'dueDate'`** (тот же фильтр `selectTodayTasks`, что использует
   Today), в формате "выполнено / всего". Задачи без срока или с другим
   сроком в этот счётчик не входят
5. Счётчик `'Habits'` — "количество привычек, отмеченных сегодня /
   общее количество привычек" — не связан с streak (серией дней подряд),
   считает только сегодняшний день
6. Счётчик `'Active goals'` — **вводит в заблуждение по названию**: это
   просто общее количество целей (`goals.length`), без какой-либо
   фильтрации по прогрессу. Цель со `'progress' = 100` тоже учитывается
   в этом числе
7. Все три счётчика пересчитываются реактивно при любом изменении
   соответствующих данных — отдельного запроса к серверу для них нет,
   используются те же `tasks`/`goals`/`habits` из общих провайдеров
8. В подвале сайдбара, под счётчиками — два переключателя, оба
   реализованы как `Switch`, а не выпадающий список:
   1. `LanguageToggle` — переключает интерфейс между EN и RU (см.
      `07. Localization.md`)
   2. `ThemeToggle` — переключает между тёмной и светлой темой (см.
      `08. Theme.md`)
   3. Оба переключателя видны только на десктопном сайдбаре — в
      `MobileNav` их нет

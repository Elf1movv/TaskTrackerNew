# 05.01. Today Dashboard [Frontend]

# Описание

Главная страница приложения — сводка на сегодня: задачи на сегодня,
прогресс по всем целям (в паре с напоминаниями — карточка-переключатель,
см. п. 8), привычки, назначенные на сегодняшний день недели. Своей
серверной логики нет — собирает и фильтрует данные, которые уже приходят
через `TaskProvider`/`GoalProvider`/`HabitProvider`/`ReminderProvider`.

# Функциональные требования

1. Шапка страницы — крупная дата (день недели, число, месяц и год) и
   кнопка "Add task" (обычная форма без зафиксированной категории и без
   зафиксированной даты — дата по умолчанию берётся из логики самой
   формы, то есть сегодня)
2. `'todayTasks'` (`selectTodayTasks`,
   `src/entities/task/lib/selectTodayTasks.ts`) — задача попадает на
   Today по одному из следующих правил:
   1. У задачи есть `'dueDate'` — показывается ровно в день, когда
      `'dueDate'` равен сегодняшней дате, и ни в какой другой — как и
      раньше, без изменений
   2. У задачи `'dueDate' = null` и она **не выполнена**
      (`'completed' = false`) — показывается на Today **каждый день**,
      пока её не выполнят, независимо от того, когда она была создана
   3. У задачи `'dueDate' = null` и она **выполнена** — показывается ещё
      в день выполнения (`'completedAt'` того же календарного дня, что
      сегодня), на следующий день пропадает молча
   4. История правила: до 2026-09-21 бездатная задача оставалась на
      Today бессрочно вне зависимости от статуса — реальный баг (см.
      `LEARNING.md`). 2026-09-21 это исправили, но перегнули палку —
      бездатная задача стала видна **только в день создания**
      (`'createdAt'`), пропадая на следующий день независимо от
      `'completed'`; это лишило пользователя возможности видеть на
      Today невыполненную задачу без даты дольше одного дня. По прямой
      обратной связи 2026-09-23 (невыполненные бездатные задачи пропадали
      с главного экрана, оставаясь доступными только на вкладке "Задачи")
      правило переписано на текущее — п. 2.2–2.3 (см. `LEARNING.md`,
      2026-09-23). `'createdAt'` для правила больше не используется
3. `'habits'` на Today (`selectTodayHabits`,
   `src/entities/habit/lib/selectTodayHabits.ts`) — только привычки, у
   которых сегодняшний день недели (`new Date().getDay()`) входит в
   `'activeDays'`; привычка вне сегодняшнего расписания на Today не
   рендерится вовсе (не показывается приглушённой — просто отсутствует
   в списке). Управлять такой привычкой (редактировать/удалить/отметить
   задним числом) можно только со страницы Habits, см. `03.02. Habit
   History-FRONTEND.md`. Цели на этой странице по-прежнему **не
   фильтруются** — показываются все, независимо от прогресса или даты
4. Три блока на странице: карточка сегодняшних задач (2/3 ширины на
   широких экранах), карточка-переключатель "Прогресс целей ↔
   Напоминания" (1/3 ширины, см. п. 8) — оба в одном ряду, и сетка
   привычек на всю ширину под ними
5. `TodayTasksCard` показывает полосу прогресса (выполнено/всего) и
   список сегодняшних задач с полным CRUD (переключение, редактирование,
   удаление — без диалогов подтверждения) плюс переупорядочивание внутри
   этого списка
6. Переупорядочивание задач на Today — **отдельный** от переупорядочивания
   на странице Tasks и от переноса дат в Calendar набор перетаскиваний
   (разные внутренние типы для drag-and-drop), но в конечном счёте меняет
   то же самое поле `'order'` у той же самой задачи
7. Пустое состояние карточки задач — "No tasks for today"
8. Третий блок ряда — не фиксированная сводка целей, а
   `GoalReminderSwapCard`: карточка "Прогресс целей" (`GoalProgressSummary`)
   и карточка "Напоминания" (`ReminderSummary`) делят одну ячейку сетки,
   переключаются круглой кнопкой в правом верхнем углу карточки. Кнопка
   несёт бейдж с числом предстоящих напоминаний и тултип с разбивкой
   "всего/критичных", а сама карточка при заходе на Today один раз
   автоматически открывается на "Напоминаниях", если они есть. Полное
   описание анимации переключения, обеих карточек, бейджа/тултипа/
   автооткрытия, фильтра приоритета в `ReminderSummary` и клика по строке
   цели (переход на редактирование, п. 21-23 `02.01. Goal
   CRUD-FRONTEND.md`) — в `13.02. Reminder Entity-FRONTEND.md`, пп. 20-33
   (эта фича рассматривается как единое целое, а не отдельно для каждой
   из двух карточек)
9. Помимо этих трёх блоков, на Today (как и на любой другой защищённой
   странице) виден глобальный колокольчик напоминаний в правом верхнем
   углу экрана — он не часть раскладки страницы Today, смонтирован один
   раз в `RootLayout` наравне с кнопкой настроек, см.
   `13.03. Reminder Bell-FRONTEND.md`

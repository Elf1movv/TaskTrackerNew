# 05.01. Today Dashboard [Frontend]

# Описание

Главная страница приложения — сводка на сегодня: задачи с сегодняшним
сроком, прогресс по всем целям, все привычки. Своей серверной логики
нет — собирает и фильтрует данные, которые уже приходят через
`TaskProvider`/`GoalProvider`/`HabitProvider`.

# Где находится (файлы)

- `src/pages/today/ui/TodayPage.tsx` — сама страница
- `src/pages/today/connectors/TodayProvider.tsx` — `todayTasks` (фильтр),
  `goals`/`habits` (без фильтра)
- `src/pages/today/lib/formatHeroDate.ts` — форматирование даты в шапке
- `src/widgets/today-tasks-card/ui/TodayTasksCard.tsx` +
  `ui/components/TodayTaskRow.tsx`
- `src/widgets/goal-progress-summary/` — см. `02.01. Goal
  CRUD-FRONTEND.md`
- `src/widgets/habit-tracker-grid/` — см. `03.01. Habit
  CRUD-FRONTEND.md`

# Функциональные требования

1. Шапка страницы — крупная дата (день недели, число, месяц и год) и
   кнопка "Add task" (обычная форма без зафиксированной категории и без
   зафиксированной даты — дата по умолчанию берётся из логики самой
   формы, то есть сегодня)
2. `'todayTasks'` — задачи, у которых `'dueDate'` равен сегодняшней дате
   (`selectTodayTasks`). Цели и привычки на этой странице **не
   фильтруются** — показываются все, независимо от прогресса или даты
3. Три блока на странице: карточка сегодняшних задач (2/3 ширины на
   широких экранах), сводка прогресса целей (1/3 ширины) — оба в одном
   ряду, и сетка привычек на всю ширину под ними
4. `TodayTasksCard` показывает полосу прогресса (выполнено/всего) и
   список сегодняшних задач с полным CRUD (переключение, редактирование,
   удаление — без диалогов подтверждения) плюс переупорядочивание внутри
   этого списка
5. Переупорядочивание задач на Today — **отдельный** от переупорядочивания
   на странице Tasks и от переноса дат в Calendar набор перетаскиваний
   (разные внутренние типы для drag-and-drop), но в конечном счёте меняет
   то же самое поле `'order'` у той же самой задачи
6. Пустое состояние карточки задач — "No tasks for today"

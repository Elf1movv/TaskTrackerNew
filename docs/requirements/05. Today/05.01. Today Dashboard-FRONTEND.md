# 05.01. Today Dashboard [Frontend]

# Описание

Редакция ветки product-logic-redesign, 2026-10-02. Главная показывает
заметки перед глазами, привычки, напоминания и обзор активных целей.
Список всех задач и недельное расписание сюда не переносятся.

- `src/pages/today/ui/TodayPage.tsx`
- `src/widgets/notes-card/ui/NotesCard.tsx`

- `src/pages/today/ui/components/GoalReminderSwapCard.tsx`
- `src/widgets/habit-tracker-grid/`

# Функциональные требования

1. Основная кнопка создаёт заметку. Бывший TodayTasksCard заменён NotesCard.
2. Заметки имеют вкладки «Актуальные / Предстоящие / Архив». Без даты
   запись видна сразу; будущая дата `'showFrom'` задаёт первый день показа.
   Запись не исчезает после этого дня и не становится просроченной.
3. Заголовок обязателен, описание необязательно. Описание в строке
   сокращается до двух строк, раскрывается в пределах ширины карточки,
   растёт по высоте и переносит длинные слова. Редактирование — внутри блока.
4. Архивирование ручное, восстановление сохраняет дату появления.
   Будущая восстановленная запись возвращается в «Предстоящие».
5. После создания будущей заметки показывается уведомление с переходом
   в «Предстоящие». В длинном списке первые 10 заметок, затем «Показать ещё».
6. Заметки не попадают в Tasks, Calendar и статистику выполнения.
7. Соседний блок целей/напоминаний не растягивается вслед за описанием заметки.
8. Все созданные блоки привычек доступны сразу, включая пустые и блоки
   без привычек на сегодняшний день. Существующие расписания не меняются.
9. Привычки, приветствие, переключение карточки целей/напоминаний и
   существующее поведение прошлых напоминаний сохраняются.

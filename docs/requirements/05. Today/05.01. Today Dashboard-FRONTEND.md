# 05.01. Today Dashboard [Frontend]

# Описание

Редакция ветки product-logic-redesign, итерация 3.1 2026-11-08 (тестовый
стенд). Главная показывает заметки перед глазами, привычки, напоминания и
обзор активных целей. Список всех задач и планы календаря сюда не
переносятся: полоса «Сегодня по плану» из третьей итерации удалена в 3.1
вместе с `TodayPlansStrip.tsx` и `selectTodayPlans.ts`.

# Функциональные требования

## Заметки

1. Основная кнопка в шапке страницы («Добавить заметку», `notes.add`)
   открывает/закрывает `NoteForm` над карточками (`TodayPage.tsx:49-70`).
   Бывший TodayTasksCard заменён `NotesCard`.
2. Заметки имеют вкладки «Актуальные / Архив»: актуальные —
   `'archivedAt' === null`, архив — остальные. Дат у заметок нет:
   в `NoteForm` только название и описание.
3. Заголовок обязателен, описание необязательно. Описание в строке
   полностью скрывается/раскрывается стрелкой, даже для одной строки.
   Раскрытый текст размещается в пределах ширины карточки,
   растёт по высоте и переносит длинные слова. Редактирование — внутри блока.
4. Архивирование ручное, восстановление возвращает запись в «Актуальные».
5. Список постраничный — 5 заметок на страницу (`NOTES_PAGE_SIZE`,
   `NotesCard.tsx:24`), внизу карточки общий `Pager`: кнопки ← «Назад» /
   → «Далее» (`pagination.previous`/`pagination.next`) и подпись
   «Страница N из M» (`pagination.page`). При одной странице `Pager` не
   рендерится. Если текущая страница перестала существовать (запись
   архивирована, перенесена или удалена), показывается последняя
   (`paginate`, `pager.tsx:58`). Смена вкладки сбрасывает страницу на
   первую. Кнопки «Показать ещё» больше нет.
6. Заметки не попадают в Tasks, Calendar и статистику выполнения, пока
   их явно не перенесли в задачи (п. 11).
7. Соседний блок целей/напоминаний не растягивается вслед за описанием заметки.
8. Галочка заметки обратимо зачёркивает её; запись остаётся на месте,
   пока пользователь отдельно не архивирует или удалит её.
9. Ручка перестановки поддерживает мышь, касание и стрелки клавиатуры.
   Порядок сохраняется во всех вкладках после перезагрузки. Соседи для
   стрелок ↑/↓ берутся из полного списка вкладки, а не из текущей
   страницы (`NotesCard.tsx:63-69`), поэтому первую/последнюю заметку
   страницы можно сдвинуть на соседнюю страницу.
10. Удаление доступно в обеих вкладках, включая старые записи, через AlertDialog.
11. Перенос заметки в задачи (`NotesCard.tsx:96-124`):
    1. В строке заметки кнопка «Перенести в задачи» (иконка `ListPlus`)
    2. Нажатие заменяет строку формой `TaskForm` с `'draft'` —
       название и описание заметки подставлены; приоритет, категория и
       срок — значения по умолчанию новой задачи
       (см. [01.01. Task CRUD-FRONTEND](../01.%20Tasks/01.01.%20Task%20CRUD-FRONTEND.md))
    3. «Отмена» закрывает форму, заметка не меняется
    4. Сохранение («Добавить задачу») вызывает `moveNoteToTask` —
       `POST /api/notes/:id/to-task` с `'expectedUpdatedAt'` заметки и
       полями формы (`'id'` новой задачи генерируется на клиенте,
       `'completedAt' = null`). Обычный `addTask` не вызывается — дубликата нет
    5. Успех: перечитываются заметки и задачи, toast «Заметка перенесена
       в задачи», форма закрывается
    6. Ошибка (сеть, 400/404/409): toast.error «Не удалось перенести
       заметку — попробуйте ещё раз», заметки перечитываются, форма
       остаётся открытой. Кнопка сохранения заблокирована, пока запрос идёт
    7. Серверная логика — [14.01. Note Entity-BACKEND](../14.%20Notes/14.01.%20Note%20Entity-BACKEND.md), п. 6

## Цели и напоминания

12. Справа от заметок — карточка-переключатель `GoalReminderSwapCard`
    (прогресс целей ↔ напоминания), её устройство — [13.02. Reminder
    Entity-FRONTEND](../13.%20Reminders/13.02.%20Reminder%20Entity-FRONTEND.md).
13. «Прогресс целей» (`GoalProgressSummary`) получает активные цели
    (`'progress' < 100`, `TodayProvider.tsx:14`) и показывает только
    первые 5 из них (`goals.slice(0, 5)`, `GoalProgressSummary.tsx:18`)
    в порядке вкладки Goals — тот же общий порядок, который меняет
    `reorderGoals`. Остальные открываются ссылкой «Все цели» на `/goals`.
14. «Напоминания» (`ReminderSummary`) показывают 5 ближайших на
    страницу с тем же `Pager`; смена фильтра «Все»/«Критичные» сбрасывает
    страницу на первую (`ReminderSummary.tsx:22,71-74`).

## Привычки

15. Под карточками — виджет привычек `HabitTrackerGrid`: привычки без
    блока простым списком, ниже именованные блоки, свёрнутые по
    умолчанию (открытие запоминается на сессию браузера). Подробно —
    [03.04. Today Habit Groups-FRONTEND](../03.%20Habits/03.04.%20Today%20Habit%20Groups-FRONTEND.md).
16. Все созданные блоки привычек доступны сразу, включая пустые и блоки
    без привычек на сегодняшний день. Существующие расписания не меняются.

# 05. Today (Dashboard)

Главная страница-сводка на сегодня. Не хранит собственных данных —
собирает и фильтрует то, что уже приходит из Notes, Goals, Reminders и
Habits. Планов календаря на Today нет (полоса «Сегодня по плану» удалена
в итерации 3.1, 2026-11-08); длинные списки заметок и напоминаний
постраничные.

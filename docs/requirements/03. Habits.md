# 03. Habits

Привычки с расписанием по дням недели (`'activeDays'`), отметкой
выполнения и подсчётом серии дней подряд (streak, с учётом расписания).
Streak — чисто клиентский расчёт, на сервере не хранится. Today
показывает только привычки, назначенные на сегодняшний день недели, и
всегда плоским списком без группировки; отдельная страница Habits
(`/habits`) показывает **все** привычки и их историю — это единственное
место, где привычку вне сегодняшнего расписания можно отредактировать,
удалить или отметить задним числом, и единственное место, где привычки
сгруппированы в именованные сворачиваемые блоки (см. 03.03).

- [03.01. Habit CRUD-FRONTEND](./03.%20Habits/03.01.%20Habit%20CRUD-FRONTEND.md)

  streak, удаление с подтверждением, переупорядочивание
- [03.01. Habit CRUD-BACKEND](./03.%20Habits/03.01.%20Habit%20CRUD-BACKEND.md)
- [03.02. Habit History-FRONTEND](./03.%20Habits/03.02.%20Habit%20History-FRONTEND.md)

  на странице `/habits`
  (без BACKEND — использует существующие методы Habit CRUD, см. выше)
- [03.03. Habit Groups-FRONTEND](./03.%20Habits/03.03.%20Habit%20Groups-FRONTEND.md)

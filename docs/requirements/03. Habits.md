# 03. Habits

Привычки с расписанием по дням недели (`'activeDays'`), отметкой
выполнения и подсчётом серии дней подряд (streak, с учётом расписания).
Streak — чисто клиентский расчёт, на сервере не хранится. Today
показывает только привычки, назначенные на сегодняшний день недели;
отдельная страница Habits (`/habits`) показывает **все** привычки и их
историю — это единственное место, где привычку вне сегодняшнего
расписания можно отредактировать, удалить или отметить задним числом.
Привычки сгруппированы в именованные сворачиваемые блоки (`HabitGroup`,
см. 03.03) — общий список блоков и их относительный порядок между
`/habits` и Today, но устройство самой карточки блока и порядок привычек
**внутри** блока — разные на каждом экране (03.03 — `/habits`, 03.04 —
Today).

- [03.01. Habit CRUD-FRONTEND](./03.%20Habits/03.01.%20Habit%20CRUD-FRONTEND.md)
  — форма (включая пикер дней недели и выбор блока), карточка/строка,
  streak, удаление с подтверждением, переупорядочивание
- [03.01. Habit CRUD-BACKEND](./03.%20Habits/03.01.%20Habit%20CRUD-BACKEND.md)
- [03.02. Habit History-FRONTEND](./03.%20Habits/03.02.%20Habit%20History-FRONTEND.md)
  — устройство сетки по дням/месяцам, графика, сводки внутри одного блока
  на странице `/habits`
  (без BACKEND — использует существующие методы Habit CRUD, см. выше)
- [03.03. Habit Groups-FRONTEND](./03.%20Habits/03.03.%20Habit%20Groups-FRONTEND.md)
  — сущность блока привычек (`HabitGroup`), CRUD (включая цвет), блок
  "Общие" (редактируемый, кроме удаления), устройство блока на `/habits`,
  перетаскивание блоков и привычек между ними
- [03.03. Habit Groups-BACKEND](./03.%20Habits/03.03.%20Habit%20Groups-BACKEND.md)
- [03.04. Today Habit Groups-FRONTEND](./03.%20Habits/03.04.%20Today%20Habit%20Groups-FRONTEND.md)
  — карточки блоков на Today (цветная "пилюля"-заголовок), фильтр "только
  блоки с привычками на сегодня", независимый порядок привычек внутри
  блока (`'todayOrder'`)
  (без BACKEND — использует те же методы Habit/HabitGroup CRUD, включая
  `PATCH /api/habits/reorder-today`, описанный в 03.01-BACKEND)

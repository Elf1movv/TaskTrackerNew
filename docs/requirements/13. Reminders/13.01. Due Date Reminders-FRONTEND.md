# 13.01. Due Date Reminders [Frontend]

# Описание

Тост-напоминание о приближающемся или уже просроченном сроке — общий
механизм для задач и целей. Не визуальный компонент (`return null`) —
чистая эффект-логика, монтируется один раз в `RootLayout`, а не на
конкретной странице, и срабатывает при загрузке приложения. В проекте
нет service worker, push-подписки или Notification API — это тост
внутри открытого приложения, а не настоящее push/фоновое уведомление.

# Функциональные требования

1. Эффект ничего не делает, пока оба провайдера не закончили начальную
   загрузку — `'isLoaded'` у `TaskProvider` **и** `'isLoaded'` у
   `GoalProvider` должны быть `true`. `'isLoaded'` был впервые вынесен
   наружу через `TaskContextValue`/`GoalContextValue` именно для этой
   проверки — до этой фичи наружу не отдавался
2. `'isDueSoonOrOverdue'(dateKey)` — общий для задач и целей помощник:
   `'dateKey'` "сегодня", "завтра" или уже в прошлом → `true`. Сравнение
   идёт как сравнение строк `"yyyy-MM-dd"` с ключом завтрашнего дня
   (`dateKey <= завтра`) — лексикографическое сравнение работает
   корректно благодаря формату с ведущими нулями. `null` → `false`
3. Задачи, попадающие в напоминание — незавершённые (`'completed' =
   false`) с `'dueDate'`, для которого `'isDueSoonOrOverdue'` вернул
   `true`. Задачи без `'dueDate'` (`null`) не попадают
4. Цели, попадающие в напоминание — с `'progress' < 100` (а не
   `'completed'`, у цели такого поля нет) и `'targetDate'`, для которого
   `'isDueSoonOrOverdue'` вернул `true`
5. Если подходящих задач хотя бы одна — показывается **ровно один**
   тост на все задачи сразу (не по одному на каждую), с текстом
   "У вас {count} задач(и) с приближающимся сроком" /
   "You have {count} task(s) due soon" и кнопкой-действием "Перейти" /
   "View", переход по которой — `navigate("/tasks")`
6. Независимо от п. 5, если подходящих целей хотя бы одна — второй,
   отдельный тост с текстом "У вас {count} цел(и) с приближающимся
   сроком" / "You have {count} goal(s) due soon" и кнопкой "Перейти" /
   "View" → `navigate("/goals")`. Тосты про задачи и про цели никогда не
   объединяются в один — на одной загрузке их может быть 0, 1 или 2
7. Дедуп — не чаще одного тоста на тип сущности в календарный день.
   Флаг хранится в `localStorage` под ключом
   `mytracker-reminders-shown-<userId>-<yyyy-MM-dd>`, значение —
   `{ tasks?: boolean, goals?: boolean }`. Ключ включает `'userId'`, а
   не только дату — иначе на одном браузере с двумя разными аккаунтами,
   вошедшими в один день, первый аккаунт мог бы молча погасить
   напоминание для второго. Перезагрузка страницы в тот же день, после
   того как тост уже показан, повторно его не покажет
8. Если `localStorage` недоступен (приватный режим, заблокированное
   хранилище) — чтение флага и его запись просто проглатывают
   исключение; тост в этом случае может показываться повторно при
   каждой перезагрузке в рамках одной сессии, но приложение не падает

# Известные ограничения

1. Это не настоящее push-уведомление — сработает только пока вкладка
   приложения открыта и провайдеры успели загрузиться. Закрытое
   приложение или фоновая вкладка напоминания не покажут

# 02. Goals

Долгосрочные цели с прогрессом. С итерации 3.1 (2026-11-08) цель —
двухуровневое дерево: подцели (`'subgoals'`) со своими этапами и
собственные этапы цели (`'milestones'`). Прогресс считается автоматически
— `(выполненные этапы цели + Σ доля выполненных этапов подцелей) / (этапы
цели + подцели)` — и пересчитывается сервером, не задаётся вручную. С 2026-11-08 у цели есть необязательная категория —
та же сущность `Category`, что у задач; на странице Goals по ней есть фильтр.

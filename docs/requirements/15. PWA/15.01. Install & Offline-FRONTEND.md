# 15.01. Install & Offline [Frontend]

# Описание

Всё, что делает сайт устанавливаемым приложением: манифест, иконки,
service worker со страницей «Нет подключения», кнопка «Установить
приложение» в настройках и цвет системной панели в цвет темы.

# Где находится (файлы)

- `public/manifest.webmanifest` — имя, старт, ярлыки, иконки, цвета
- `public/icons/` — `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`,
  `apple-touch-icon.png`
- `index.html` — ссылка на манифест, `apple-touch-icon`,
  `apple-mobile-web-app-*`, `theme-color`
- `public/sw.js` — service worker (плюс обработчики push, см. 13.05)
- `public/offline.html` + `public/offline.js` — страница «Нет подключения»
  (отдельный файл скрипта: политика безопасности CSP запрещает встроенные
  скрипты)
- `src/shared/lib/pwa/pwa.ts` — `initPwa()` (вызывается из `src/main.tsx`
  до отрисовки), `usePwaInstall()`, `isStandalone()`, `useThemeColorSync()`
  (вызывается из `src/app/providers/AppProviders.tsx`)
- `src/widgets/settings-panel/ui/components/InstallAppButton.tsx` — кнопка
  и инструкция для iPhone
- `scripts/qa/pwa.mjs` — браузерная проверка (входит в `run-local.sh`)

# Функциональные требования

## Манифест

1. `name`/`short_name` — «MyTracker», `start_url` — `/today`, `scope` —
   `/`, `display` — `standalone` (своё окно без адресной строки), `lang` —
   `ru`, цвета фона и темы — `#0b1117`
2. Иконки 192 и 512 (`any`) и маскируемая 512 (`maskable`, для круглых и
   скруглённых значков Android)
3. Ярлыки (долгое нажатие на значок): «Задачи» `/tasks`, «Привычки»
   `/habits`, «Календарь» `/calendar`
4. iPhone: `apple-touch-icon`, `apple-mobile-web-app-capable`,
   `apple-mobile-web-app-title` «MyTracker»,
   `apple-mobile-web-app-status-bar-style` `black`

## Service worker

5. Регистрируется в `initPwa()` после события `load` и **только в
   собранном сайте** (`import.meta.env.PROD`): в `npm run dev` он держал бы
   старые страницы между правками
6. При установке кладёт в кеш `mytracker-offline-v1` только
   `/offline.html`, `/offline.js` и `/icons/icon-192.png`; при активации
   удаляет кеши других версий
7. Перехватывает только переходы по страницам (`request.mode ===
   "navigate"`) и сами файлы офлайн-страницы. Всегда сначала сеть; если
   сети нет — переход получает `/offline.html`. Скрипты, стили и API **не
   кешируются** — после выкладки никто не застрянет на старой версии
8. Страница «Нет подключения»: «Нет подключения к интернету», «MyTracker
   пока работает только онлайн…», кнопка «Повторить» (перезагрузка);
   перезагружается сама по событию `online`. Тема и язык — из
   `localStorage` (`theme`, `mytracker-language`)

## Кнопка «Установить приложение»

9. `usePwaInstall()` возвращает `mode`:
   1. `"prompt"` — браузер прислал `beforeinstallprompt` (Android Chrome,
      Chrome/Edge на компьютере). `initPwa()` ловит событие заранее (оно
      приходит до появления React) и отменяет мини-панель браузера —
      предложение установить живёт в настройках
   2. `"ios"` — iPhone/iPad (iPadOS выдаёт себя за Mac, поэтому ещё
      проверяется сенсорный экран)
   3. `null` — уже установлено (`display-mode: standalone` или
      `navigator.standalone`) или браузер не умеет устанавливать — кнопки нет
10. Кнопка в панели настроек (`InstallAppButton`, над «Пройти знакомство
    заново»):
    1. `"prompt"` — закрывает панель и показывает окно установки браузера.
       Событие одноразовое: после ответа оно сбрасывается, браузер может
       прислать новое позже
    2. `"ios"` — окно «Установить MyTracker на iPhone» с двумя шагами:
       «Нажмите „Поделиться“ внизу экрана Safari» и «Выберите „На экран
       «Домой»“, включите „Открыть как веб-приложение“ и нажмите
       „Добавить“», кнопка «Понятно»
11. После установки (`appinstalled`) кнопка пропадает

## Цвет системной панели

12. `useThemeColorSync(theme)` при смене темы ставит
    `<meta name="theme-color">` = цвет `--background` текущей темы
    (запасной — `#0b1117`) — строка состояния телефона и заголовок окна
    приложения сливаются со страницей. Чтение — в следующем кадре: эффект
    срабатывает раньше, чем `ThemeProvider` ставит класс темы на `<html>`

# Известные ограничения

1. Без сети работает только страница «Нет подключения» — данных офлайн нет
   (решение владельца)
2. Браузеры без установки PWA (например, Яндекс Браузер на Android) кнопку
   не показывают — `beforeinstallprompt` там не приходит
3. На iPhone установка только вручную через меню «Поделиться» в Safari

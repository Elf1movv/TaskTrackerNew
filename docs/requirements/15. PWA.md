# 15. PWA

MyTracker можно установить как приложение (PWA, с 2026-11-12, выпущено на
прод в тот же день): значок на экране телефона или в меню компьютера, своё
окно без адресной строки, старт с «Сегодня», ярлыки «Задачи / Привычки /
Календарь». Офлайн с данными **не** делаем (решение владельца,
`docs/PRODUCT_STRATEGY.md`, раздел 6): без сети показывается только своя
страница «Нет подключения». Приложение из магазинов (Google Play) — не
раньше 500–1000 пользователей (там же, раздел 7).

Push-уведомления используют тот же service worker, но описаны в
[13.05. Push Notifications](./13.%20Reminders.md).

  из `public/`)

# 15. PWA

MyTracker можно установить как приложение (PWA, с 2026-11-12, выпущено на
прод в тот же день): значок на экране телефона или в меню компьютера, своё
окно без адресной строки, старт с «Сегодня», ярлыки «Задачи / Привычки /
Календарь». Офлайн с данными **не** делаем (решение владельца,
`docs/PRODUCT_STRATEGY.md`, раздел 6): без сети показывается только своя
страница «Нет подключения». Приложение из магазинов (Google Play) — не
раньше 500–1000 пользователей (там же, раздел 7); до тех пор в Яндекс
Браузере и похожих на Android предлагаем открыть сайт в Chrome.

Push-уведомления используют тот же service worker, но описаны в
[13.05. Push Notifications](./13.%20Reminders.md).

- [15.01. Install & Offline-FRONTEND](./15.%20PWA/15.01.%20Install%20%26%20Offline-FRONTEND.md)
  (без BACKEND — своих серверных методов нет; сервер только отдаёт файлы
  из `public/`)

## Изменения 2026-11-18 (заставка при обновлении)

Если при запуске service worker нашёл новую версию, `public/splash.js` больше
не перезагружает страницу посреди заставки: ждёт конца анимации (заставку при
этом не убирает и `hideSplash()`), ставит `sessionStorage`
`mytracker-splash-hold` и перезагружается; новая страница показывает
последний кадр (`data-splash-mode="hold"`, ~0,35 с). Раньше вторая загрузка
шла в короткую версию, и заставка выглядела оборванной. Вибрация при
заставке невозможна (браузер не даёт вибрировать до первого касания, iPhone
не даёт вовсе).

## Изменения 2026-11-18 (кеш данных)

После первого входа телефон хранит последнюю подтверждённую сервером копию всех разделов (`localStorage`, ключ `mytracker-cache:v1:<id пользователя>:<раздел>`).

- При следующем запуске экраны заполняются из копии сразу, а сервер сверяет данные в фоне. Изменения с другого устройства появляются через долю секунды.
- Правки, которые ещё не дошли до сервера, в копию не попадают.
- Выход из аккаунта и истёкшая сессия стирают копию. Вход другим пользователем стирает чужую.
- Без сети копия показывается, но правки без сети по-прежнему не сохраняются.

Подробности — `docs/ARCHITECTURE.md`, «Кеш данных на телефоне».

## Изменения 2026-11-18 (смотреть без сети — шаг 1)

Без интернета приложение открывается, если на этом устройстве уже входили и не выходили:
- **Последний вошедший** (`mytracker-cache:last-user`: id и почта) хранится рядом с копией данных. Его стирает выход из аккаунта.
- **Запуск без связи.** Если проверка входа не дошла до сервера, а последний вошедший есть, приложение показывает сохранённое. Флаг `markStartedOffline` хранится в `shared/lib/pwa/networkStatus.ts`. Иначе, как раньше, показывается `/offline.html`.
- **Плашка «Нет сети — только просмотр сохранённого»** (`app/layouts/OfflineBanner.tsx`) видна под верхней полосой и при запуске без сети, и при пропаже связи посреди работы (событие `offline`).
- **Правки** (создать, изменить, удалить, переставить) в любом разделе отклоняются с сообщением «Нет сети — изменить пока нельзя» (`usePersistedCollection`). На сервер ничего не уходит.
- **«Выйти»** без сети выключено: выйти без сервера нельзя.
- **Появилась связь.** После запуска без сети страница перезагружается за заставкой, после пропажи посреди работы — плашка просто исчезает.

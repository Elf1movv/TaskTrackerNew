# 10. Feedback

Виджет обратной связи, добавленный **временно, на период бета-тестирования**
— тонкая плашка внизу каждой защищённой страницы, открывающая форму
"текст + опциональный скриншот", которая сохраняется в базе и (если
настроен получатель) уходит письмом. Не постоянная часть продукта — см.
"Известные ограничения" в дочерних доках.

- [10.01. Feedback Widget-FRONTEND](./10.%20Feedback/10.01.%20Feedback%20Widget-FRONTEND.md)
  — плашка, модалка с формой, флаг `FEEDBACK_BETA_ENABLED`
- [10.01. Feedback Widget-BACKEND](./10.%20Feedback/10.01.%20Feedback%20Widget-BACKEND.md)
  — модель `Feedback`, `POST /api/feedback`, отправка письма

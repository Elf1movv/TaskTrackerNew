# 08. Theme

Переключатель светлой/тёмной темы оформления. Построен на уже
установленной библиотеке `next-themes` (была в зависимостях и раньше,
неявно использовалась `shared/ui/sonner.tsx`, но без смонтированного
`ThemeProvider` — до этой фичи переключение темы физически ничего не
меняло, см. `08.01`). Управляется из сайдбара (`06. Navigation`), но сама
палитра — общеприкладной CSS, поэтому вынесена отдельным пунктом дерева.

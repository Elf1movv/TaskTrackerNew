# 11.03. Welcome Back Greeting [Frontend]

# Описание

Короткая исчезающая надпись «с возвращением» при обычном повторном входе
на `/today`. До 2026-11-10 этот файл назывался «Welcome Screens» и
описывал ещё модалку первого входа `WelcomeModal`; её заменил онбординг —
см. [11.01. Onboarding Flow-FRONTEND](./11.01.%20Onboarding%20Flow-FRONTEND.md).

# Где находится (файлы)

- `src/widgets/onboarding/ui/WelcomeBackGreeting.tsx` — сама надпись
- `src/pages/auth/ui/LoginPage.tsx` — выбирает адрес после входа
- `src/pages/today/ui/TodayPage.tsx` — читает query-параметр, монтирует
  надпись, зачищает URL
- `src/shared/lib/i18n/dictionaries/en.ts` / `ru.ts` — ключи
  `onboarding.back.*`

# Функциональные требования

## Адрес после входа

1. После успешного входа `LoginPage` делает полный переход браузера
   (`window.location.href`, не `navigate()` — см.
   [09.01. Account Access-FRONTEND](../09.%20Authentication/09.01.%20Account%20Access-FRONTEND.md),
   «Известные ограничения», п. 1):
   1. Если в адресе входа есть `'verified' === "1"` (первый вход сразу после
      подтверждения почты) → `/today?firstLogin=1`
   2. Иначе → `/today?welcomeBack=1`
2. `?firstLogin=1` с 2026-11-10 ничего не показывает: первый вход
   определяется статусом онбординга на сервере, а параметр нужен только
   затем, чтобы новичок не увидел «с возвращением». `TodayPage` его просто
   удаляет из адреса

## `TodayPage`

3. Если `'welcomeBack' === "1"` — рендерится `<WelcomeBackGreeting
   onDone={clearGreetingParam} />`
4. `clearGreetingParam` удаляет `'firstLogin'` и `'welcomeBack'` из URL
   через `setSearchParams(..., { replace: true })` — F5 после этого
   приветствие не повторяет

## `WelcomeBackGreeting`

5. При монтировании один раз выбирается случайный текст из 7 вариантов
   (`onboarding.back.1`…`onboarding.back.7`) через `useState(() => ...)`
6. Надпись видна 2,2 секунды (`setTimeout`), затем exit-анимация
   (`motion`/`AnimatePresence`); `onDone` вызывается из `onExitComplete`,
   то есть после завершения анимации
7. Контейнер имеет `pointer-events-none` — клики под надписью не
   блокируются

# Известные ограничения

1. Если человек закрыл онбординг на середине и вошёл снова, он увидит и
   «с возвращением», и продолжение онбординга (надпись исчезает через
   2,2 секунды и клики не перехватывает, поэтому это не мешает)

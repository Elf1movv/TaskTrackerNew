# 04. Calendar

Пять видов календаря — Повестка дня, День, Неделя, Месяц, Год — над
общей инфраструктурой (переключатель видов, `'anchorDate'`,
синхронизация с URL). Показывает и позволяет двигать по дням задачи,
цели, напоминания и привычки. Работает поверх обычного CRUD этих
сущностей (`01. Tasks`, `02. Goals`, `13. Reminders`, `03. Habits`) —
своих серверных методов не имеет.

# 01. Tasks

Задачи — базовая сущность приложения: заголовок, необязательное
описание, приоритет, категория, необязательный срок выполнения, статус
выполнения (с отметкой момента выполнения), ручной порядок.

С 2026-09-29 `'dueDate'` — не просто необязательное поле, а разделитель
между двумя разными списками задачи: без `'dueDate'` — недатированный
инбокс "Общие задачи" (виден на Today и странице Tasks), с `'dueDate'` —
план дня, виден **только** в Calendar (см. `04. Calendar.md`).
Отдельного действия "перенести в календарь" нет — задача переходит
из одного списка в другой сама, как побочный эффект обычного
редактирования (включение/выключение тумблера даты в той же форме,
см. `01.01. Task CRUD-FRONTEND.md`, п. 5, 11.1).

# 01. Tasks

Общие дела по категориям с приоритетом, описанием, сроком и выполнением.
Не создают календарных планов и не входят в цели; срок виден в календаре
маркером. На Today живут заметки, их можно перенести в задачи.
На странице Tasks один фильтр — категория; активные задачи идут по сроку
(датированные первыми), переставлять вручную можно только задачи без
срока; выполненные — в свёрнутом разделе «Выполненные (N)», по 10 на
страницу.

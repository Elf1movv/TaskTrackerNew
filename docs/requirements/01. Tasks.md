# 01. Tasks

Задачи — базовая сущность приложения: заголовок, необязательное
описание, приоритет, категория, необязательный срок выполнения, статус
выполнения (с отметкой момента выполнения), ручной порядок.

С 2026-10-02 Tasks — общий список, Today — компактное представление,
Calendar — представление тех же задач по `'dueDate'`. Назначение даты
не скрывает задачу из списков и не создаёт новую запись. На Tasks есть
фильтр «Все / Без даты / С датой», в строках Tasks/Today — дата и
переход в Calendar. Выполненные в списках видны до конца дня выполнения.

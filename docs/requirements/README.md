# Документация требований

Дерево функциональных требований по фичам — что должно делать
приложение и как это устроено на клиенте/сервере. Формат и правила
именования — `STYLE_GUIDE.md` в этой же папке.

Отличие от остальных доков в `docs/`:
- `docs/ARCHITECTURE.md` — **почему** так устроено технически (паттерны,
  компромиссы, gotchas)
- `docs/DEPLOYMENT.md` — продовая инфраструктура
- `docs/requirements/` (этот файл) — **что именно** должна делать каждая
  фича, по шагам, достаточно подробно, чтобы можно было восстановить
  поведение приложения только по этим файлам

Дерево полностью покрывает текущий функционал приложения (обновлено
2026-09-22 — сущность `Reminder` получила поле `'priority'`
(`'normal'`/`'critical'`, см. "13.02. Reminder Entity"): циклический
переключатель в форме, визуальный признак приоритета в списках и фон в
сетке календаря (форма признака менялась позже, см. запись ниже,
2026-09-22), кастомный `TimePicker` заменил нативный `<input
type="time">`. На Today
карточка-переключатель "Прогресс целей ↔ Напоминания" обзавелась
бейджем/тултипом с числом предстоящих напоминаний и автоматически
открывается на "Напоминаниях", если они есть. Тот же бейдж и попап
ближайших напоминаний теперь доступны глобально на каждой странице через
новый "13.03. Reminder Bell". Критичные напоминания дополнительно
получили собственный модальный поп-ап по мере приближения срока —
"13.04. Critical Reminder Alerts").
Дальше — поддерживать в актуальном состоянии по `<WhenToUpdate>` из
`STYLE_GUIDE.md`: новая функциональность → новый `NN.MM.` файл,
изменение поведения → правка существующего файла, а не создание нового
рядом.

Обновлено 2026-09-22 (три независимые правки, без новых файлов в дереве):
клик по строке цели на Today теперь раскрывает эту цель на странице
Goals и переставляет её первой в списке (было — сразу открывало форму
редактирования), см. "02. Goals"; цветные кружки-индикаторы приоритета у
задач и напоминаний заменены иконками (`PriorityDot`/
`ReminderPriorityIcon`, форма намекает на уровень, не только цвет),
приоритет напоминания теперь виден для обоих уровней (`normal`/
`critical`), а не только критичного, и попутно закрыт пробел — карточка
сегодняшних задач на Today вообще не показывала приоритет, см. "01.
Tasks" и "13. Reminders"; график под сеткой истории привычек выровнен
пиксель-в-пиксель с колонками дат сетки и получил переключатель из 4
стилей визуализации (area/bar/step/ring), см. "03. Habits".

Обновлено 2026-09-23 (три независимые правки, без новых файлов в дереве):
правило видимости бессрочной (без `'dueDate'`) задачи на Today
пересмотрено ещё раз — невыполненная видна каждый день, пока не будет
выполнена (не только в день создания, как было с 2026-09-21), выполненная
пропадает на следующий день после `'completedAt'`, закрыто unit-тестом,
см. "05. Today"; строка задачи (Tasks/Today/панель дня Calendar)
выровнена по верхнему краю вместо центра — длинные названия в 2+ строки
больше не сдвигают чекбокс/иконку приоритета/бейдж категории вниз
относительно однострочных задач рядом, см. "01. Tasks"; стиль "кольцо"
переключателя графика истории привычек убран по обратной связи
("непонятно, где круг и процентовка") — остались area/bar/step, `Ring`-
компонент и всё, что было нужно только ему, удалены, а не скрыты, см.
"03. Habits".

Обновлено 2026-09-23 (второй заход в тот же день, пять точечных правок
в "Напоминаниях" + одна в "Обратной связи"): дата напоминания теперь
всегда редактируема при правке (раньше `lockedDate`, нужный только для
быстрого добавления из панели дня, случайно делал дату НАВСЕГДА
нередактируемой); дата видна в списках на Today и в попапе глобального
колокольчика (раньше только время); бейдж-счётчик остался только на
глобальном колокольчике, убран с дублирующей локальной кнопки на
карточке Today (заодно снял наложение тултипа на кнопку "Добавить
задачу"); иконка приоритета в строке напоминания — в колонке
фиксированной ширины, текст больше не гуляет по горизонтали в
зависимости от того, какая иконка отрисовалась — см. "13. Reminders".
Письмо с обратной связью показывает имя/email отправителя вместо
служебного `userId` (лукап по уже существующему аккаунту, без нового
поля в форме) — см. "10. Feedback".

Обновлено 2026-09-23 (третий заход в тот же день, четыре точечных правки,
без новых файлов в дереве): глобальный колокольчик (`13.03. Reminder
Bell`) скрыт на `/today` — там теперь только локальная кнопка на карточке
`GoalReminderSwapCard`, и бейдж-счётчик/`Tooltip`, убранные с неё в
предыдущем (втором) заходе того же дня как дублирующие, вернулись на неё
же, раз она снова единственный источник этой информации на своей
странице (см. "13. Reminders"); иконка приоритета у задач (Tasks, Today)
наконец выстроена в одну колонку — исправлено через фиксированную
ширину `w-20` бейджа категории (`TaskRow.tsx`, `TodayTaskRow.tsx`),
переопределяющую его дефолтный `w-fit`, причина отдельная от выравнивания
`items-start`, закрытого тем же днём раньше (см. "01. Tasks"); строка
напоминания (`ReminderRow`, попап `ReminderBell`) переверстана на
двухколоночный `grid` — заголовок больше не обрезается серединой слова
теперь, когда в той же строке есть дата (см. "13. Reminders"); счётчик
"выполнено" в заголовке страницы Tasks считается только за сегодня
(`isCompletedToday`), а не за всё время — согласован со списком задач
под заголовком, который уже скрывал старые выполненные задачи (см. "01.
Tasks").

# 02.01. Goal CRUD [Frontend]

# Описание

Редакция ветки product-logic-redesign, 2026-10-02. Цель описывает результат,
задачи — действия для его достижения. Связь необязательная. Независимый
чек-лист milestones заменён связанными задачами с общим выполнением.

# Где находится (файлы)

- `src/entities/goal/model/GoalProvider.tsx`
- `src/features/goal-form/ui/GoalForm.tsx`
- `src/widgets/goal-list/ui/components/GoalAccordionItem.tsx`
- `src/pages/goals/ui/GoalsPage.tsx`
- `src/widgets/legacy-transition/ui/LegacyTransition.tsx`

# Функциональные требования

1. Сохранить название, описание, цвет, необязательный срок и ручной порядок.
2. В раскрытой цели показывать задачи с соответствующим `'goalId'`.
   Выполнение и редактирование относятся к той же записи, что в Tasks.
3. Создание задачи внутри цели предзаполняет её связь с этой целью.
4. Показатель «Выполнено X из Y задач» считает задачи с равным весом.
   Процент отражает количество, а не трудоёмкость. Цель без задач имеет
   пустое состояние и 0%, не считается достигнутой.
5. Даже 100% задач не меняют `'achievedAt'`. «Цель достигнута» — отдельное
   подтверждаемое действие. Невыполненные задачи не завершаются автоматически.
6. Переключатель «Активные / Достигнутые» сохраняет историю и позволяет
   вернуть цель в активные. Today и счётчик активных целей исключают достигнутые.
7. Удаление цели отвязывает задачи, сохраняя их, планы и напоминания;
   подтверждение объясняет это последствие.
8. Старые milestones доступны в одноразовом разборе: создать задачу либо
   выбрать существующую. При выборе существующей её статус показывается
   заранее и сохраняется. Самостоятельные milestone-чекбоксы удалены.

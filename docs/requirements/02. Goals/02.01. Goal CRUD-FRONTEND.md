# 02.01. Goal CRUD [Frontend]

# Описание

Создание, редактирование, удаление и переупорядочивание целей, плюс
управление вложенными подцелями (milestones) внутри каждой цели —
добавление, переключение, редактирование текста, удаление и
переупорядочивание milestone'ов.

# Где находится (файлы)

- `src/features/goal-form/ui/GoalForm.tsx` — форма цели (add + edit)
- `src/features/add-milestone/ui/AddMilestoneForm.tsx` — добавление
  milestone
- `src/features/milestone-row/ui/MilestoneRow.tsx` — toggle/edit/delete/
  drag одного milestone
- `src/features/delete-goal/` — кнопка удаления цели
- `src/entities/goal/model/goal.ts` — типы `Goal`, `Milestone`,
  `GOAL_COLORS`
- `src/entities/goal/model/GoalProvider.tsx` — вся бизнес-логика:
  `addGoal`/`updateGoal`/`deleteGoal`/`reorderGoals`/`addMilestone`/
  `updateMilestone`/`deleteMilestone`/`reorderMilestones`/
  `toggleMilestone`, пересчёт `'progress'`
- `src/widgets/goal-list/ui/GoalList.tsx` +
  `ui/components/GoalAccordionItem.tsx` — список целей на странице Goals
- `src/widgets/goal-progress-summary/ui/GoalProgressSummary.tsx` +
  `ui/components/GoalProgressRow.tsx` — сводка целей на Today
- `src/pages/goals/connectors/GoalsProvider.tsx` — вычисляемое поле
  `'dueLabel'` (не часть типа `Goal`, только для отображения)

# Функциональные требования

## Форма цели

1. Форма `GoalForm` принимает необязательный проп `'goal'` — так же, как
   `TaskForm`: передан → режим редактирования (`updateGoal`), не
   передан → режим добавления (`addGoal`)
2. Поле `'title'` — обязательное, `.trim()` проверяется перед
   сохранением. В отличие от `TaskForm`, Enter в этом поле **не**
   сохраняет форму
3. Поле `'description'` — многострочное, необязательное, `.trim()`
4. Поле `'targetDate'` — по умолчанию сегодняшняя дата для новой цели
5. Поле `'color'` — один из `GOAL_COLORS` (5 фиксированных цветов), по
   умолчанию первый цвет из списка
6. `'milestones'` и `'progress'` не редактируются через эту форму —
   `'milestones'` при создании всегда `[]`, `'progress'` всегда `0`

## Milestones

7. Добавление milestone (`AddMilestoneForm`) — одно текстовое поле +
   кнопка (задизейблена, если поле пустое/пробелы), Enter тоже
   отправляет. Поле очищается после добавления
8. Переключение выполнения (`toggleMilestone`) — клик по кружку у
   milestone
9. Редактирование текста — клик по названию milestone превращает его в
   поле ввода; сохраняется по потере фокуса или Enter, отменяется по
   Escape или если после `.trim()` осталась пустая строка (возвращается
   исходный текст)
10. Удаление milestone — иконка корзины, видна только при наведении,
    без диалога подтверждения
11. Переупорядочивание milestone'ов — drag-and-drop, работает **только
    внутри одной цели** (нельзя перетащить milestone из одной цели в
    другую)
12. `'progress'` пересчитывается по формуле: `round(количество
    выполненных / общее количество × 100)`, либо `0`, если milestone'ов
    нет вообще (не `NaN`). Пересчитывается после добавления/удаления/
    переключения milestone — но **не** после простого редактирования
    текста или после переупорядочивания (эти действия не меняют
    количество выполненных)
13. Все операции с milestones — чисто локальный пересчёт массива
    `'milestones'` (и `'progress'`) с одним вызовом обновления всей
    цели целиком — отдельных серверных методов на сами milestones не
    существует (см. `02.01. Goal CRUD-BACKEND.md`)

## Список целей (страница Goals)

14. Список — аккордеон, в любой момент **развёрнута только одна цель**;
    первая цель в списке развёрнута по умолчанию при загрузке страницы
15. В свёрнутом виде видно: кольцо прогресса, заголовок, описание,
    `"{выполнено}/{всего} milestones"`, срок (`'dueLabel'`).
    Milestone'ы видны только когда цель развёрнута
16. Кнопки редактирования и удаления цели видны всегда, независимо от
    состояния развёрнутости
17. Удаление цели — без диалога подтверждения, удаляет её вместе со
    всеми milestones безвозвратно
18. Переупорядочивание целей — drag-and-drop по всей строке цели
19. Пустое состояние — "No goals yet" (только если форма добавления не
    открыта в этот момент)

## Сводка целей на Today

20. `GoalProgressSummary` показывает **все** цели (без фильтрации),
    каждую строкой: заголовок (обрезан до 2 строк), `{progress}%`,
    полоса прогресса
21. Здесь тоже доступно переупорядочивание — использует ту же
    операцию `reorderGoals`, что и список на странице Goals (это один и
    тот же порядок, просто два разных места, откуда его можно менять)
22. Редактирование и удаление здесь недоступны — только просмотр и
    перетаскивание

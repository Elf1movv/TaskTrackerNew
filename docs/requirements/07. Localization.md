# 07. Localization

Переключатель языка интерфейса (English / Russian). Собственная простая
реализация (`src/shared/lib/i18n/`), без библиотеки (`i18next` и
подобные не подключались) — сознательно, по тому же принципу "не
усложнять", что уже применялся в проекте раньше (например, `Goal.
milestones` как встроенный JSON вместо отдельной таблицы). Управляется
из сайдбара (`06. Navigation`), но сама система переводов используется
по всему приложению, поэтому вынесена отдельным пунктом дерева, а не
подпунктом Navigation.

  приложении нет, состояние живёт только в `localStorage` браузера)

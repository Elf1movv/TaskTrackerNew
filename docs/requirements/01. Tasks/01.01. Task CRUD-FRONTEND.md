# 01.01. Task CRUD [Frontend]

Редакция второй итерации, 2026-10-10. Общие дела живут во вкладке задач.

1. Заголовок, описание, категория, приоритет, необязательный срок dueDate.
   Срок не создаёт план календаря. Выбора цели и кнопки планирования нет.
2. Активные задачи по умолчанию; фильтры категории, статуса и срока
   применяются совместно. Фильтры срока — кнопки в стиле приложения.
3. История выполненных по 10 на страницу, completedAt по убыванию,
   затем id. Для старой записи без completedAt используется updatedAt.
   При смене фильтров страница сбрасывается, при возврате записи в
   активные корректируется. Активный список лимитом не ограничен.
4. Галочка меняет только эту задачу. Удаление удаляет только задачу.
   Ни цель, ни календарные планы, ни заметки от этих действий не меняются.
5. /tasks?task=<id> открывает редактирование, включая выполненные записи.
6. Старые legacyPending доступны в общем разборе до явного выбора
   одного назначения. Выбор «Задача» не создаёт дополнительных планов.
7. Формы и списки: src/features/task-form, src/widgets/task-board,
   src/entities/task, src/pages/tasks. Ошибки сохранения показываются toast.
8. Срок задачи с 2026-11-08 виден в календаре маркером (Месяц, панель дня,
   Список), но планом не становится — см. 04.02 и 04.03.
9. `TaskForm` (`src/features/task-form/ui/TaskForm.tsx`) для новой задачи
   принимает необязательные пропы:
   1. `'draft'` — `{ title, description }`, подставляются в поля новой
      задачи. Остальные поля — обычные значения по умолчанию: приоритет
      `"medium"`, первая категория (или `'lockedCategory'`), срок выключен
      без `'defaultDueDate'`
   2. `'onCreate'` — заменяет `addTask`: форма передаёт поля задачи
      (`'completed' = false`) и ждёт `Promise<boolean>`. `false` — форма
      остаётся открытой; `true` — закрывается. Пока ожидание идёт, кнопка
      сохранения заблокирована и повторное сохранение (в т.ч. Enter) игнорируется
   3. При редактировании существующей `'task'` оба пропа игнорируются
   4. Используется переносом заметки в задачи (см. 05.01, п. 16)

# 13. Reminders

Сквозная фича — предупреждает о приближающемся или уже прошедшем сроке
для задач и целей сразу. Не "часть" Tasks или Goals по отдельности:
читает данные из обоих провайдеров одним общим механизмом и монтируется
один раз в `RootLayout`, а не на конкретной странице. Своих данных не
хранит и собственного API-метода не имеет.

- [13.01. Due Date Reminders-FRONTEND](./13.%20Reminders/13.01.%20Due%20Date%20Reminders-FRONTEND.md)
  (без BACKEND — читает уже загруженные `tasks`/`goals` из
  `TaskProvider`/`GoalProvider`, ничего не отправляет на сервер)

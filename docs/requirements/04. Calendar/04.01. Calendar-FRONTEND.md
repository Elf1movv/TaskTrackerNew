# 04.01. Calendar [Frontend]

# Описание

Помесячный просмотр задач с возможностью посмотреть/добавить/
отредактировать/удалить задачи конкретного дня и перетащить задачу на
другой день. Своей серверной логики нет — под капотом это обычный
`PATCH /api/tasks/:id`, меняющий только `'dueDate'` (см.
`01.01. Task CRUD-BACKEND.md`). День, которому принадлежит задача, не
всегда равен `'dueDate'` — см. п. 5 (правило `isTaskOnDay`).

# Где находится (файлы)

- `src/pages/calendar/ui/CalendarPage.tsx` — раскладка страницы, условный
  рендер панели дня и анимация её появления/закрытия
  (`motion/react`)
- `src/pages/calendar/connectors/CalendarProvider.tsx` — состояние
  месяца/выбранного дня, `selectedTasks`, `moveTaskToDay`
- `src/pages/calendar/lib/buildMonthGrid.ts` — построение сетки дней
  месяца
- `src/entities/task/lib/isTaskOnDay.ts` — принадлежит ли задача
  конкретному дню календаря (см. ниже)
- `src/widgets/calendar-grid/ui/CalendarGrid.tsx` +
  `ui/components/CalendarDayCell.tsx` — сама сетка календаря
- `src/widgets/day-detail-panel/ui/DayDetailPanel.tsx` +
  `ui/components/DayTaskRow.tsx` — панель выбранного дня с CRUD

# Функциональные требования

1. Сетка календаря — 7 колонок (дни недели, сокращённо), плюс пустые
   ячейки-заглушки в начале месяца, чтобы 1-е число встало на
   правильный день недели. Неделя начинается с **понедельника**, не с
   воскресенья (`WEEKDAY_LABELS`, `src/shared/lib/i18n/dateLocale.ts` —
   `["Mo", "Tu", ..., "Su"]`/`["Пн", "Вт", ..., "Вс"]`); заглушки в начале
   месяца считаются со сдвигом `(getDay(monthStart) + 6) % 7`
   (`src/pages/calendar/lib/buildMonthGrid.ts:15`), а не напрямую
   `getDay()` — `date-fns`'s `getDay()` сам по себе воскресенье-первый
   (`0 = Sun`), сдвиг переводит его в понедельник-первый, синхронно с
   `WEEKDAY_LABELS`
2. Каждая ячейка дня показывает число и до **3** цветных точек —
   приоритеты задач этого дня (`PriorityDot`, набор задач дня определяется
   правилом `isTaskOnDay`, см. п. 5). Если задач на день больше трёх —
   оставшиеся никак не отображаются (нет счётчика "+N")
3. Сегодняшний день выделен визуально отдельно от выбранного дня. У
   каждой ячейки дня всегда видимая рамка (`border border-border`,
   `src/widgets/calendar-grid/ui/components/CalendarDayCell.tsx:36`) — не
   только при наведении, выборе или на сегодняшнем дне
4. Навигация — кнопки "предыдущий месяц"/"следующий месяц" и кнопка
   "Today", которая одновременно возвращает и текущий месяц, и выбранный
   день на сегодня
5. Задача принадлежит дню календаря (`isTaskOnDay`,
   `src/entities/task/lib/isTaskOnDay.ts`) по одному из двух правил:
   1. `'dueDate'` задачи совпадает с этим днём — обычный случай
   2. Либо, если у задачи `'dueDate' = null`: задача выполнена
      (`'completed' = true`) и `'completedAt'` приходится на этот день —
      задача без срока, отмеченная выполненной, появляется в календаре в
      день, когда её выполнили, хотя у неё никогда не было `'dueDate'`.
      Без этого правила такая задача пропадала бы отовсюду сразу после
      выполнения (см. правило видимости на странице Tasks,
      `01.01. Task CRUD-FRONTEND.md`, п. 10), но нигде не появлялась бы
      взамен
   3. Задача без `'dueDate'`, которая ещё **не** выполнена, не
      принадлежит ни одному дню — в сетке календаря и в панели дня не
      показывается вообще, пока не получит `'dueDate'` или не будет
      выполнена
   4. Это правило используется и для точек в сетке месяца (п. 2), и для
      списка задач панели выбранного дня (`selectedTasks`, п. 6)
6. Панель выбранного дня (справа от сетки) видна, только пока какой-то
   день выбран:
   1. По умолчанию, при открытии страницы Calendar, ни один день не
      выбран (`selectedDay = null`,
      `src/pages/calendar/connectors/CalendarProvider.tsx:13`) — панель
      не рендерится вовсе, никакая ячейка сетки не подсвечена как
      выбранная (`isSelected` в `CalendarGrid.tsx` — `false`, пока
      `selectedDay` не задан)
   2. Клик по ячейке дня в сетке выбирает этот день (`selectDay(day)`)
      — под сеткой открывается панель с задачами именно этого дня,
      отобранными по правилу `isTaskOnDay` (п. 5)
   3. Кнопка закрытия (иконка `X`, lucide-react) в шапке панели, рядом с
      кнопкой добавления задачи — клик снимает выбор дня
      (`selectDay(null)`), панель закрывается
   4. Кнопка "Today" (п. 4) при клике, помимо возврата к текущему
      месяцу, выбирает сегодняшний день — если панель была закрыта, она
      открывается с задачами сегодняшнего дня
   5. Появление и закрытие панели анимировано (`motion/react`:
      `AnimatePresence` + `motion.div` в `CalendarPage.tsx`,
      `initial={{opacity: 0, x: 12}}`, `animate={{opacity: 1, x: 0}}`,
      `exit={{opacity: 0, x: 12}}`, `transition={{duration: 0.2}}`) —
      лёгкое проявление с небольшим сдвигом при открытии, обратное при
      закрытии
   6. У `motion.div` панели намеренно нет `key`, привязанного к дате дня
      — переключение между двумя уже открытыми днями (клик на другую
      ячейку, когда панель уже открыта) просто меняет её содержимое, без
      повторного проигрывания анимации; анимация проигрывается только на
      переходах "ничего не выбрано ↔ выбран день" (открытие/закрытие)
7. Панель выбранного дня (`DayDetailPanel`) — полноценный CRUD задач:
   добавить, отредактировать (форма разворачивается прямо в строке),
   отметить выполненной, удалить (без диалога подтверждения) — тот же
   `TaskForm`/провайдер, что и на странице Tasks
8. Кнопка добавления задачи в панели дня открывает `TaskForm` с проп
   `'defaultDueDate'` = выбранный день — это только подставляет значение
   поля даты (`DatePicker`) на случай, если пользователь включит тумблер
   `'hasDueDate'` вручную. Сам тумблер по умолчанию **выключен**, как и
   при обычном добавлении задачи (см. `01.01. Task CRUD-FRONTEND.md`,
   п. 5.1-5.2) — то есть добавление задачи из панели дня само по
   себе не проставляет ей `'dueDate'`, если пользователь не включит
   тумблер
9. Пустое состояние панели дня — "No tasks scheduled"
10. **Перетаскивание задачи на другой день**: строка задачи в панели дня
    — источник перетаскивания, ячейка дня в сетке — цель. При наведении
    перетаскиваемой задачи на ячейку та подсвечивается кольцом. При
    отпускании — задаче меняется только `'dueDate'` на день этой ячейки,
    остальные поля не трогаются. Перетаскивание всегда выставляет
    `'dueDate'` — задача, попавшая на день только благодаря
    `'completedAt'` (п. 5.2) и не имевшая своего `'dueDate'`, при таком
    переносе получает настоящий `'dueDate'` этого дня
11. Переупорядочивание задач **внутри** панели одного дня не
    поддерживается — только перенос между днями

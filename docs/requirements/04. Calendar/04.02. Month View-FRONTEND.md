# 04.02. Month View [Frontend]

# Описание

Месячная сетка показывает планы, напоминания и сроки целей по датам.
Спецификация ветки product-logic-redesign; общая модель описана в 04.01.

# Где находится (файлы)

- `src/pages/calendar/ui/CalendarMonthView.tsx`
- `src/widgets/calendar-grid/ui/CalendarGrid.tsx`
- `src/widgets/calendar-grid/ui/components/CalendarDayCell.tsx`
- `src/widgets/day-detail-panel/`
- `src/widgets/calendar-item-popover/`

# Функциональные требования

1. Сетка начинается с понедельника, включает соседние дни для полных
   недель. Текущий/выбранный день выделены; нажатие соседнего месяца
   переключает месяц. Высота ячеек растёт с содержимым.
2. План виден только в своей `'date'`, в том числе без времени.
   Задачи со сроком без CalendarPlan не превращаются в строки календаря.
   Отложенные планы находятся в кармане над сеткой.
3. Строки планов показывают название, выполнение и заданное время.
   У связанного плана выполнение общее с задачей; при завершении
   появляется «Задача выполнена». Строки не ограничены счётчиком +N.
4. Нажатие строки открывает PlanForm у неё; чекбокс не открывает форму
   и не выбирает день повторно. Напоминание открывает ReminderForm.
   Одновременно открыта одна форма CalendarItemPopover.
5. Сроки целей показываются самостоятельными маркерами, напоминания —
   отдельными плашками (до двух, затем счётчик остальных). Обычные и
   критические напоминания различаются оформлением. Привычек в ячейке нет.
6. Нажатие свободного места дня открывает панель: справа на широком
   экране, ниже сетки на узком. При первом открытии календаря выбранного
   дня нет, если его не задаёт URL. Панель закрывается явной кнопкой.
7. Панель содержит планы, напоминания, цели и привычки выбранного дня.
   «Добавить план» открывает форму уже с выбранной датой. При выборе
   другого дня открытый черновик сохраняет текст, меняется дата создания.
   Редактирование существующей записи использует её собственную дату.
8. В панели можно создать/редактировать напоминание и цель, менять
   выполнение плана/привычки. Для всех форм используются общие компоненты.
9. Перетаскивание плана в другую ячейку меняет `'CalendarPlan.date'`,
   сохраняет часы, длительность и ссылку. Исходный срок задачи не меняется.
   Перетаскивание цели меняет её `'targetDate'`. Наведённый день подсвечен.
10. Перестановки внутри одного дня нет; порядок общих списков задач/целей
    через календарное перемещение не меняется.

# Ограничения

Большое количество планов увеличивает высоту недели. Расписание привычек
вычисляется по их текущим активным дням, а не по отдельным снимкам расписания.

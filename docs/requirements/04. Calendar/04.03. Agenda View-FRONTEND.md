# 04.03. Agenda View [Frontend]

# Описание

«Список» позволяет просматривать планы, сроки задач, напоминания и сроки целей по дням.
Спецификация ветки product-logic-redesign.

# Где находится (файлы)

- `src/pages/calendar/ui/CalendarAgendaView.tsx`
- `src/widgets/day-detail-panel/ui/components/`

# Функциональные требования

1. Начальное окно — шесть дней от опорной даты; «Показать ещё» добавляет
   шесть. Смена опорной даты сбрасывает окно. Стрелки общей шапки
   сдвигают опорную дату на 30 дней.
2. Пустые дни пропускаются. В карточке сначала планы CalendarPlan своей
   даты (включая без времени), затем сроки задач (`'allDeadlines'` с
   `'dueDate'` этого дня, включая выполненные, строкой `DayDeadlineRow` —
   см. 04.02, п. 7.1), затем напоминания и сроки целей. День только со
   сроком задачи тоже не считается пустым.
   Привычки, заметки и задачи без срока не добавляются.
3. Строки переиспользуют компоненты панели дня. Можно переключить
   выполнение или открыть общую форму редактирования. Связанный план
   меняет исходную задачу, самостоятельный — только себя.
4. Перетаскивания строк между карточками нет. Создание плана доступно
   в общей кнопке «Новый план» над календарём (04.01, п. 13); внутри
   карточек списка кнопок создания нет.
5. При отсутствии записей в окне показывается пустое состояние
   («Ничего не запланировано»). Карман «Отложено» остаётся доступен над
   видом календаря.
6. С 2026-11-08 (итерация 3.1) над карточками — поясняющая строка
   (`calendar.agendaHint`, `CalendarAgendaView.tsx:88-105`): «Повестка —
   список ближайших дней, в которые что-то есть: планы, сроки задач и
   целей, напоминания. Пустые дни пропускаются, «Показать ещё» добавляет
   {count} дней. Отмечать и править можно прямо здесь.»; `{count}` —
   шаг расширения окна (`LOAD_MORE_INCREMENT_DAYS = 6`). Строка видна и
   над пустым состоянием.

# Ограничения

При полностью пустом начальном окне кнопка расширения списка не показана;
другие периоды доступны стрелками или другими видами календаря.

# 04.03. Agenda View [Frontend]

# Описание

«Список» позволяет просматривать планы, напоминания и сроки целей по дням.
Спецификация ветки product-logic-redesign.

# Где находится (файлы)

- `src/pages/calendar/ui/CalendarAgendaView.tsx`
- `src/widgets/day-detail-panel/ui/components/`

# Функциональные требования

1. Начальное окно — шесть дней от опорной даты; «Показать ещё» добавляет
   шесть. Смена опорной даты сбрасывает окно. Стрелки общей шапки
   сдвигают опорную дату на 30 дней.
2. Пустые дни пропускаются. В карточке сначала планы CalendarPlan своей
   даты (включая без времени), затем напоминания и сроки целей.
   Привычки, заметки и непланированные задачи не добавляются.
3. Строки переиспользуют компоненты панели дня. Можно переключить
   выполнение или открыть общую форму редактирования. Связанный план
   меняет исходную задачу, самостоятельный — только себя.
4. Перетаскивания строк между карточками нет. Создание плана доступно
   в общей кнопке над календарём; внутри карточек списка кнопок создания нет.
5. При отсутствии записей в окне показывается пустое состояние.
   Карман «Отложено» остаётся доступен над видом календаря.

# Ограничения

При полностью пустом начальном окне кнопка расширения списка не показана;
другие периоды доступны стрелками или другими видами календаря.

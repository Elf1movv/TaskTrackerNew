# 04.01. Calendar Infrastructure [Frontend]

# Описание

Календарь показывает самостоятельные планы CalendarPlan.
Общие задачи не связываются с планами. Срок задачи не создаёт интервалы.
Спецификация ветки product-logic-redesign.

# Где находится (файлы)

- `src/pages/calendar/connectors/CalendarProvider.tsx`
- `src/pages/calendar/ui/CalendarPage.tsx`
- `src/entities/calendar-plan/`
- `src/features/plan-form/`
- `src/widgets/calendar-timeline/ui/PlanShelf.tsx`

# Функциональные требования

1. Виды: Список, День, Неделя, Месяц, Год. Начальный вид — День.
   На экране уже 768 px вместо Недели открывается День. Переключатели,
   карточки и формы используют существующие компоненты и цвета темы.
2. Стрелки сдвигают опорную дату на день/неделю/месяц/год; в Списке —
   на 30 дней. «Сегодня» возвращает к текущей дате. URL отражает
   `'view'` и `'date'`; ссылка с `'plan'` открывает редактирование плана.
3. PlanProvider читает `/api/plans`; название, описание и выполнение
   принадлежат самому плану.
   Некоторые внутренние названия `Task`/`allTasks` сохранены для геометрии
   сеток: их тип — CalendarEntry, `'dueDate'` адаптера равен `'plan.date'`.
   Запись изменений всегда идёт в CalendarPlan, не в срок Task.
4. PlanForm создаёт только план. Дата выбранного дня подставлена сразу.
   При смене дня текст черновика остаётся. Создание/изменение плана
   не добавляет и не меняет записи в Tasks/Goals/Notes.
5. Перенос между днями меняет только дату плана. Перенос по часовой сетке
   меняет начало/конец с сохранением длительности. Изменение размера
   меняет окончание и длительность. Срок задачи остаётся прежним.
6. «Отложено» виден над всеми видами даже пустым, принимает отдельный
   план перетаскиванием. У плана снимаются дата/время, сохраняются
   длительность и содержание. Возврат в сетку задаёт новое расписание.
7. «Без времени» над Днём/Неделей появляется, когда в видимом периоде
   есть датированные планы без часа. Их можно открыть или перенести
   на час. В Месяце и Списке они доступны обычными строками своих дат.
8. Чекбокс меняет только выполнение этого плана. Истечение времени
   не отмечает запись выполненной. Выполненные планы приглушены.
9. Удаление плана требует подтверждения и удаляет только этот план.
10. Напоминания и сроки целей остаются отдельными элементами. Перенос
    маркера цели меняет её срок, перенос плана — только его расписание.
11. Годовая статистика получает исходные задачи, не интервалы календаря:
    несколько планов не увеличивают число выполненных задач.

# Ограничения

Каждый интервал находится в пределах одного дня; работу на несколько
дней пользователь создаёт несколько самостоятельных планов.
Часовые виды не показывают привычки. План без даты доступен в «Отложено».

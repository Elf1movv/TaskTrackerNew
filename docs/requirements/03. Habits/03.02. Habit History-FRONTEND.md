# 03.02. Habit History [Frontend]

# Описание

Отдельная страница "Привычки" (`/habits`, между Goals и Calendar в
навигации) — история выполнения всех привычек в виде сетки по дням
(неделя/месяц) или по месяцам (год), с графиком и сводкой под сеткой. В
отличие от Today (см. `05.01. Today Dashboard-FRONTEND.md`), здесь
показываются **все** привычки, включая те, что не назначены на
сегодняшний день недели — это единственное место, где такую привычку
можно отредактировать, удалить или отметить задним числом. Своей
серверной логики нет — использует те же методы `Habit CRUD`, что и
Today (`GET`/`PATCH`/`DELETE /api/habits`, см. `03.01. Habit
CRUD-BACKEND.md`).

С 2026-09-23 привычки на этой странице сгруппированы в именованные
сворачиваемые блоки (см. `03.03. Habit Groups-FRONTEND.md`) — вся
сетка/график/переключатель периода, описанные в этом файле, теперь
существуют **в рамках одного блока**, а не на всю страницу сразу:
каждый блок рисует свою копию этой сетки независимо от остальных.
Страница `/habits` сама по себе — просто список блоков, см. `03.03.`
для устройства заголовка блока, сворачивания, перетаскивания блоков и
привычек между ними.

# Функциональные требования

## Общее устройство страницы

1. `HabitsPage` передаёт в `HabitHistoryGrid` **все** привычки из
   `useHabits()` без какой-либо фильтрации по `'activeDays'` — в отличие
   от Today, где привычка вне сегодняшнего расписания не показывается
   вовсе (`selectTodayHabits`, см. `05.01. Today Dashboard-FRONTEND.md`).
   `HabitHistoryGrid` сама раскладывает их по блокам (`habits.filter(h
   => h.groupId === group.id)`) и рендерит по одному
   `HabitGroupAccordionItem` на блок — см. `03.03. Habit
   Groups-FRONTEND.md`
2. Переключатель периода — три кнопки "Неделя"/"Месяц"/"Год"
   (`habits.period.week`/`month`/`year`), состояние чисто локальное
   (`useState`, не персистится) **у каждого блока своё**, по умолчанию
   "Неделя" (`HabitGroupAccordionItem.tsx:46`)
3. Кнопка "+ Добавить привычку" — внутри каждого блока, открывает
   встроенную `HabitForm` в режиме добавления прямо над сеткой **этого**
   блока, с `'lockedGroupId'` = этого блока; клик по иконке
   редактирования у конкретной привычки — ту же форму в режиме
   редактирования этой привычки. Открытие одной закрывает другую (общий
   `isAdding`/`editingHabit`, теперь в рамках одного блока, а не всей
   страницы, — `HabitGroupAccordionItem.tsx:49-51`)
4. Пустое состояние — "Пока нет привычек" (`habits.noHabitsYet`),
   показывается **на уровне блока**, если в этом блоке нет ни одной
   привычки и форма добавления в нём не открыта в этот момент
   (`HabitGroupAccordionItem.tsx:173-178`) — тот же паттерн, что и в
   `HabitTrackerGrid` на Today, просто теперь не общий на страницу, а
   свой у каждого блока (включая "Общие", которые всегда существуют —
   пустая страница без единой привычки всё равно показывает пустой блок
   "Общие", а не пустую страницу без блоков вовсе)
5. Страница `/habits` — `max-w-7xl` (`HabitsPage.tsx:18`), шире, чем
   раньше (`max-w-4xl`), чтобы вмещать более широкую сетку блока в
   режиме "Месяц"; блок заголовка/подзаголовка страницы сохраняет
   собственный `max-w-4xl`, чтобы текст заголовка не растягивался на всю
   ширину (`HabitsPage.tsx:19`). Плавный переход максимальной ширины
   карточки при переключении периода (был до 2026-09-23 у единственной
   карточки на всю страницу) — убран вместе с переходом на блоки:
   карточка каждого блока (`AccordionItem`, `rounded-2xl bg-card border`)
   теперь фиксированной ширины независимо от периода, сетка внутри
   неё просто становится теснее в режиме "Месяц" (см. п. 7 ниже)

## Сетка

Всё, что описано в этом разделе, теперь относится к сетке **одного
блока** (`HabitGroupAccordionItem`), не всей страницы — у каждого блока
своя независимая сетка с собственными колонками, зависящими от его
собственного выбранного периода.

6. Колонки сетки зависят от периода блока:
   1. "Неделя" — 7 дней текущей недели, понедельник-первые
      (`getPeriodDays("week", today)`)
   2. "Месяц" — все дни текущего календарного месяца
      (`getPeriodDays("month", today)`)
   3. "Год" — 12 месяцев текущего года (`getYearMonths(today)`)
   4. Подписи колонок — двухстрочные для дней, однострочные для года
      (`HabitGroupAccordionItem.tsx:182-207`):
      - "Неделя" — основная строка (10px) — короткое название дня
        недели, под ней (9px, приглушённый цвет) — число месяца
      - "Месяц" — над числом месяца (9px, приглушённый цвет) —
        короткое название дня недели, основная строка (10px) — само
        число месяца
      - "Год" — одна строка, сокращённое название месяца
        (`format(month, "LLL", { locale })` — локаль зависит от языка
        интерфейса)
7. Сетка не скроллится по горизонтали ни при каком периоде — колонки
   задаются `grid-template-columns` с `minmax(0, 1fr)` для каждой
   колонки дня/месяца (`HabitGroupAccordionItem.tsx:95`), а не
   фиксированной шириной в пикселях, поэтому весь период всегда
   помещается по ширине карточки блока — при "Месяц" (до ~31 колонки)
   ячейки становятся уже, чем при "Неделя"/"Год" (7/12 колонок), но не
   выезжают за край. Каждая ячейка — не шире 40px (`max-w-10`),
   квадратная (`aspect-square`) и **круглая** (`rounded-full`) — во всех
   трёх периодах одинаково (`HabitGroupAccordionItem.tsx:325`, ячейка
   месяца — `MonthCell.tsx:23,35`)
8. Каждая строка — одна привычка: иконка, заголовок, streak
   (`getStreak(habit.completedDates, habit.activeDays)` — тот же расчёт,
   что и везде, см. `03.01. Habit CRUD-FRONTEND.md`, п. 9), кнопки
   редактирования/удаления — видны только при наведении на строку. Та же
   строка — источник и цель перетаскивания привычки (внутри блока и
   между блоками), см. `03.03. Habit Groups-FRONTEND.md`
9. Ячейка дня (`getDayCellState`, неделя/месяц) — одно из 4 состояний:
   1. `"future"` — день позже сегодняшнего (`isAfter(date, today)`) —
      приглушённая заливка, пунктирная рамка, не кликабельна
   2. `"unscheduled"` — день недели не входит в `habit.activeDays` этой
      привычки — та же приглушённая заливка и пунктир, не кликабельна
   3. `"done"` — день в прошлом или сегодня, входит в расписание, дата
      есть в `'completedDates'` — заливка цветом привычки, сплошная
      рамка того же цвета
   4. `"pending"` — день в прошлом или сегодня, входит в расписание, но
      не отмечен — прозрачная заливка, обычная рамка
   5. Клик по ячейке в состоянии `"done"`/`"pending"` переключает
      отметку этого конкретного дня (`toggleHabit(habit.id, dateKey)`) —
      это единственное место в приложении, где отметку привычки можно
      поставить/снять **задним числом**, не только за сегодня (Today
      умеет только сегодняшний день, см. `03.01. Habit
      CRUD-FRONTEND.md`, п. 8)
10. Ячейка месяца (`MonthCell`, только годовой вид) — **кольцо прогресса**
    (`ProgressRing`, `src/shared/ui/progress-ring.tsx`), не плоская
    заливка: процент выполнения виден в центре кольца всегда, не только
    по клику. `getMonthCompletionStats(habit, month, today)` возвращает
    `{ done, scheduled }` (не готовую долю); `percent = scheduled === 0 ?
    0 : Math.round((done / scheduled) * 100)` считается в `MonthCell` и
    передаётся в `ProgressRing` как `'progress'` (`strokeWidth={4}`,
    цвет — цвет привычки):
    1. `'scheduled'` — сколько дней этого месяца входят в `'activeDays'`
       этой привычки, `'done'` — сколько из них отмечено
    2. Для текущего месяца считаются только дни по сегодняшний
       включительно — месяц, который ещё не закончился, не считается
       "отстающим" только из-за незавершённости
    3. Для будущего месяца (позже текущего) `'scheduled'` и `'done'` —
       всегда `0`
    4. Для месяца раньше даты создания привычки (`'habit.createdAt'`,
       ISO-строка) — тоже всегда `{ done: 0, scheduled: 0 }`; для
       месяца, в котором привычка была создана, считаются дни только
       начиная с реального дня создания (`createdAt.getDate()`), а не с
       1-го числа месяца (`habitCellState.ts:30-52`)
    5. Если `'scheduled' === 0` (будущий месяц или месяц до создания
       привычки) — кольцо не рисуется вовсе: ячейка становится плоским
       приглушённым кругом с пунктирной рамкой, `disabled`, без
       `Popover` — то же обращение, что у ячейки дня в состоянии
       `"future"`/`"unscheduled"` (см. п. 9)
    6. Клик по кольцу (только при `'scheduled' > 0`) открывает `Popover`
       (`@/shared/ui/popover`, Radix) рядом с ячейкой (`side="top"`) с
       названием месяца и текстом "{done} из {scheduled}"
       (`habits.monthCellSummary`) — единственное взаимодействие с
       ячейкой месяца, отметка конкретного дня из годового вида по-прежнему
       недоступна

## График и сводка

11. Под сеткой блока — блок с переключателем стиля графика (колонка 1) и
    самим графиком (колонки 2..N, `grid-column: 2 / -1`) в одной строке
    `<div className="grid" style={{ gridTemplateColumns }}>`
    (`HabitGroupAccordionItem.tsx:229-249`) — та же переменная
    `'gridTemplateColumns'`, что задаёт колонки сетки дней/месяцев выше
    (`HabitGroupAccordionItem.tsx:95`), не отдельно продублированная
    строка. Из-за этого график начинается ровно под первой колонкой
    дат/месяцев сетки выше на всех трёх периодах, а не отдельным блоком
    на всю ширину карточки
12. Переключатель стиля графика (`HabitChartStyle`) — 3 кнопки-иконки в
    колонке 1, освободившейся благодаря выравниванию (п. 11):
    `TrendingUp`/`BarChart3`/`Activity` (lucide-react, `CHART_STYLES`,
    `HabitGroupAccordionItem.tsx:26-30`). Состояние чисто локальное
    (`useState`), своё у каждого блока, не персистится между
    переключениями периода, перезагрузкой страницы или сессиями. По
    умолчанию — `"area"`:
    1. `"area"` — `AreaChart`/`Area` (recharts) со сглаженной
       интерполяцией между точками (`type="monotone"`), закруглённые
       концы и стыки линии (`strokeLinecap="round"`,
       `strokeLinejoin="round"`), точки-маркеры на каждом значении
       (увеличиваются при наведении — `activeDot`), заливка градиентом
    2. `"bar"` — `BarChart`/`Bar`, скруглённые сверху столбики
       (`radius={[4, 4, 0, 0]}`)
    3. `"step"` — `LineChart`/`Line` с `type="stepAfter"` — резкие
       ступеньки вместо сглаживания между точками, без заливки под линией
    4. Оси/сетка/тултип (`<ChartAxes />`, `HabitHistoryChart.tsx:34-60`)
       общие для всех трёх стилей, не продублированы в JSX трижды
    5. История: 2026-09-22 был добавлен четвёртый стиль, `"ring"`
       (донат-кольцо с итоговым процентом за период) — временный
       эксперимент по прямой просьбе пользователя, убран 2026-09-23 по
       прямой обратной связи ("выглядит очень плохо и непонятно, где
       круг и процентовка") — компонент и всё, что было нужно только
       ему, удалены полностью
13. Данные графика (`getHabitHistorySummary`) зависят от периода блока и
    считаются **только по привычкам этого блока** (`habits` —
    аргумент, переданный из `HabitHistoryGrid` уже отфильтрованным по
    `'groupId'`, см. `03.03. Habit Groups-FRONTEND.md`):
    1. "Неделя"/"Месяц" — одна точка на день, значение — сколько привычек
       этого блока было отмечено выполненными в этот день
    2. "Год" — одна точка на месяц, значение — суммарное количество
       выполненных привычко-дней этого блока за этот месяц
    3. В обоих случаях `"unscheduled"`/`"future"` ячейки не входят ни в
       `'completed'`, ни в `'total'` — сводка считает только дни,
       реально входившие в расписание каждой привычки
14. Под графиком — текстовая сводка "Выполнено: {completed} из {total}
    ({percent}%)" (`habits.page.summary`), тоже в рамках блока —
    `'completed'`/`'total'` те же, что использовались для построения
    графика этого блока; `'percent'` — `0`, если `'total' = 0` (не
    `NaN`). Этот блок сводки/графика вообще не рендерится, если у блока
    нет ни одной привычки (`habits.length > 0`,
    `HabitGroupAccordionItem.tsx:227`)

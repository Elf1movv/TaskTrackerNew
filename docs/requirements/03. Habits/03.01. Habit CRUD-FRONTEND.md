# 03.01. Habit CRUD [Frontend]

# Описание

Создание, редактирование, удаление и переупорядочивание привычек, плюс
ежедневная отметка "выполнено сегодня" и подсчёт текущей серии дней
подряд (streak). Каждая привычка теперь несёт расписание —
`'activeDays'`, дни недели, на которые она назначена; вне расписания
привычка не показывается на Today (см. `05.01. Today
Dashboard-FRONTEND.md`) и не засчитывается в streak, но остаётся
управляемой (редактирование/удаление/отметка задним числом) на
отдельной странице Habits — см. `03.02. Habit History-FRONTEND.md`.

# Функциональные требования

1. Форма `HabitForm` принимает необязательный проп `'habit'` — так же,
   как `TaskForm`/`GoalForm`: передан → редактирование, не передан →
   добавление
2. Поле `'title'` — обязательное, `.trim()`. Enter в этом поле сохраняет
   форму
3. Поле `'icon'` — кнопка с текущей иконкой (по умолчанию `"✨"`),
   открывающая `Popover` (`@/shared/ui/popover`) с сеткой готовых эмодзи
   (`HABIT_ICONS`, `src/entities/habit/model/habitIcons.ts` — ~48 штук,
   тематическая подборка под привычки: спорт, здоровье, учёба, быт).
   Клик по эмодзи в сетке выбирает его и закрывает поповер. Свободный
   ввод произвольного текста в это поле недоступен
4. Поле `'color'` — один из `HABIT_COLORS` (`src/entities/habit/model/habit.ts:10` —
   12 фиксированных цветов). Выбранный цвет отмечен контрастной обводкой
   (`var(--foreground)`), а не обводкой того же цвета, что и сам кружок
5. Поле `'activeDays'` — расписание привычки по дням недели
   (`src/features/habit-form/ui/HabitForm.tsx`):
   1. 7 кнопок-переключателей, порядок — понедельник-первый
      (`MONDAY_FIRST_WEEKDAYS`, `src/shared/lib/date.ts:24` —
      `[1, 2, 3, 4, 5, 6, 0]`), подписи — `getWeekdayLabels()`; каждая
      кнопка хранит настоящее значение `Date.getDay()` (`0`=воскресенье
      .. `6`=суббота), не индекс в массиве
   2. Клик по кнопке переключает этот день в `'activeDays'`
      (`toggleDay`) — независимо друг от друга, можно выключить любое
      подмножество
   3. Для новой привычки по умолчанию выбраны **все 7 дней**
      (`ALL_DAYS`) — не сужает поведение для тех, кто не трогает эту
      настройку
   4. Кнопка сохранения (Add/Save) задизейблена, если `'activeDays'`
      пуст — привычка без единого активного дня сохраниться не может
   5. В режиме редактирования поле предзаполняется `habit.activeDays`
6. Новая привычка всегда создаётся с `'completedDates' = []` — это не
   поле формы, задаётся в `addHabit`
7. Новая привычка (`addHabit`) добавляется **в конец** списка, не в
   начало — то же правило, что у задач и целей, см. `01.01. Task
   CRUD-FRONTEND.md`, п. 8
8. Отметка "выполнено сегодня" (`toggleHabit`) — клик по всей карточке
   целиком, не отдельным контролом. Добавляет или убирает сегодняшнюю
   дату из `'completedDates'`
9. **Серия дней подряд (streak)** — считается назад от сегодняшнего дня
   и, начиная с этой фичи, **учитывает расписание** (`getStreak(dates,
   activeDays)`, `src/entities/habit/lib/getStreak.ts`):
   1. Если сегодня — активный по расписанию день и он не отмечен, streak
      сразу `0`, даже если раньше были отмечены дни подряд
   2. Если сегодня не активный по расписанию день — сегодняшний день не
      требует отметки и не обнуляет streak сам по себе; расчёт просто
      продолжается с предыдущего дня
   3. Дальше отсчёт идёт назад по календарным дням: активный по
      расписанию день без отметки обрывает streak; неактивный по
      расписанию день пропускается (не засчитывается, но и не обрывает
      серию) — привычка "Пн/Ср/Пт" не теряет streak из-за пропущенного
      вторника, на который она никогда не была назначена
   4. Расчёт ограничен 3650 итерациями (~10 лет) как защита от
      зависания, а не как ожидаемый предел использования
10. Вид списка привычек переключается кнопками "Сетка"/"Список"
    (`ToggleGroup`, `src/widgets/habit-tracker-grid/ui/HabitTrackerGrid.tsx`)
    — выбор сохраняется в `localStorage`
    (`mytracker-habit-view`, `habitViewMode.ts`) и переживает перезагрузку
    страницы:
    1. Сеточный вид — 2 колонки на мобильном, 4 на desktop
       (`HabitCard`), карточки одинаковой высоты независимо от длины
       заголовка (`h-full` на карточке + CSS Grid растягивает строку по
       умолчанию) — до этой фичи короткий заголовок делал карточку
       короче соседних
    2. Списочный вид — по одной привычке в строке на всю ширину
       (`HabitListRow`)
    3. Кнопки редактирования/удаления — общий абсолютно спозиционированный
       оверлей поверх правого верхнего угла карточки/строки
       (`HabitGridItem.tsx`), виден только при наведении. В списочном
       виде надпись streak справа зарезервировала под этот оверлей
       место (`pr-14` в `HabitListRow.tsx`) — раньше при наведении иконки
       редактирования/удаления визуально накладывались на streak
11. Удаление привычки (`deleteHabit`) требует подтверждения — клик по
    иконке корзины открывает `AlertDialog` ("Удалить привычку?" /
    предупреждение, что вместе с привычкой удаляется вся история), тот
    же компонент, что и у других деструктивных подтверждений в проекте
    (например, удаление категории). До 2026-09-21 привычка удалялась
    сразу по клику, без диалога — несогласованно с остальным проектом;
    найдено QA-прогоном и исправлено в тот же день
12. Переупорядочивание привычек — drag-and-drop по всей карточке/строке,
    тот же общий механизм (`useDragReorder` + `usePersistedCollection.reorder()`,
    один сетевой запрос за раз, без гонок и дедлоков), что у задач — см.
    `01.01. Task CRUD-FRONTEND.md`, п. 9
13. Пустое состояние — "No habits yet" (только если форма добавления не
    открыта)

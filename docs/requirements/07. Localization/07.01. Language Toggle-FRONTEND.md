# 07.01. Language Toggle [Frontend]

# Описание

Переключение языка интерфейса между English и Russian. Собственная
минималистичная реализация — плоские словари строк с точечными ключами
и функция интерполяции `{var}`, без сторонней i18n-библиотеки. Отдельно
от словарей строк — локализация названий месяцев/дней недели в
`date-fns`-форматировании дат (своя карта `Language → Locale`).

# Где находится (файлы)

- `src/shared/lib/i18n/dictionaries/en.ts`,
  `src/shared/lib/i18n/dictionaries/ru.ts` — плоские словари `{ключ:
  строка}`, ключи в точечной нотации (`"tasks.title"`,
  `"taskForm.due"`, ...)
- `src/shared/lib/i18n/languageContext.ts` — тип `Language` (`"en" |
  "ru"`), тип `TranslationKey` (`keyof typeof en` — ключи словаря `ru`
  обязаны совпадать с ключами `en`, иначе тип не соберётся), контекст,
  хук `useLanguage()`
- `src/shared/lib/i18n/LanguageProvider.tsx` — состояние, персист в
  `localStorage`, сама функция `t()`. Вынесен в отдельный файл от
  `languageContext.ts` специально для правила линтера
  `react-refresh/only-export-components` — тот же приём, что у
  `entities/task/model/taskContext.ts` + `TaskProvider.tsx`
- `src/shared/lib/i18n/dateLocale.ts` — `getDateLocale(language)` (карта
  `Language → date-fns/locale`, `enUS`/`ru`) и
  `getWeekdayLabels(language)` (свой список сокращений дней недели для
  шапки календаря — не через `date-fns`, потому что это не единичный
  `format()`-вызов, а массив коротких подписей колонок)
- `src/shared/ui/language-toggle.tsx` — сам переключатель, `Switch` на
  экране "Внешний вид" панели настроек (см.
  [12.01. Settings Panel-FRONTEND](../12.%20Settings/12.01.%20Settings%20Panel-FRONTEND.md))
- `src/app/providers/AppProviders.tsx` — `LanguageProvider` смонтирован
  **выше** (снаружи) провайдеров сущностей (`TaskProvider`/
  `GoalProvider`/`HabitProvider`/`CategoryProvider`)

# Функциональные требования

1. `useLanguage()` возвращает `{ language, setLanguage, t }`:
   1. `'language'` — `"en"` или `"ru"`
   2. `setLanguage(next)` — переключает язык и сохраняет выбор
   3. `t(key, vars?)` — возвращает строку из словаря текущего языка по
      ключу `'key'`; если `'vars'` передан, каждое вхождение `{имя}` в
      строке заменяется на значение `vars.имя` (например,
      `t("tasks.loadMore", { count: 7 })` → `"Load 7 more"`)
   4. Если ключа нет в словаре текущего языка — `t()` возвращает сам
      ключ как строку (запасной вариант, не падает и не показывает
      пустоту)
2. Язык по умолчанию — `"en"`. При старте приложения читается
   `localStorage` (ключ `"mytracker-language"`): если там `"ru"` —
   стартовый язык `"ru"`, при любом другом значении (включая отсутствие
   ключа или недоступность `localStorage`, например в приватном режиме
   браузера) — `"en"`
3. `setLanguage()` сохраняет выбор в `localStorage` под тем же ключом.
   Если запись в `localStorage` бросает исключение — язык всё равно
   переключается для текущей сессии, просто не переживёт перезагрузку
   страницы (ошибка проглатывается тихо, не показывается пользователю)
4. `LanguageToggle` (`shared/ui/language-toggle.tsx`) — один `Switch` с
   подписями "EN"/"RU" по бокам, а не выпадающий список из двух пунктов.
   Активная сторона подсвечена (`text-foreground`), неактивная —
   приглушена (`text-muted-foreground`)
5. Что переводится — весь текст интерфейса, который не является
   пользовательским контентом: подписи навигации, кнопки, плейсхолдеры
   форм, статусы, пустые состояния, тексты toast-уведомлений об ошибках
   сохранения (см. `usePersistedCollection`)
6. Что **сознательно не** переводится:
   1. Пользовательский контент — заголовки/описания задач, целей,
      привычек, названия категорий. Это данные пользователя, не текст
      интерфейса приложения
   2. Название приложения "MyTracker" в шапке сайдбара — это
      название бренда, а не переводимая строка интерфейса (см.
      `06.01. Sidebar Stats-FRONTEND.md`)
7. Название сущности в toast-сообщениях (`toast.createFailed` и т.п.)
   собирается через `ENTITY_TRANSLATION_KEYS` в
   `usePersistedCollection.ts` — маленькая карта `entityLabel → ключ
   словаря` (`"task" → "toast.entityTask"`, аналогично для `"goal"`,
   `"habit"`, `"category"`), а не сам `entityLabel` напрямую, потому что
   `entityLabel` — техническое английское слово, не рассчитанное на показ
   пользователю на RU
8. `LanguageProvider` смонтирован в `AppProviders.tsx` **выше**
   провайдеров сущностей — потому что `usePersistedCollection` вызывает
   `useLanguage()` для перевода своих toast-сообщений об ошибках, а
   значит `LanguageProvider` должен быть предком
   `TaskProvider`/`GoalProvider`/`HabitProvider`/`CategoryProvider`, а не
   наоборот
9. Локализация дат (не строк интерфейса, а названий месяцев/дней недели
   в `date-fns`) — отдельный механизм (`dateLocale.ts`), задействован во
   всех местах, где дата форматируется для показа человеку:
   `shared/ui/date-picker.tsx`, `pages/goals/lib/formatTargetDate.ts`,
   `pages/today/lib/formatHeroDate.ts`, `SidebarNav.tsx`,
   `pages/calendar/ui/CalendarPage.tsx`,
   `widgets/day-detail-panel/ui/DayDetailPanel.tsx`,
   `widgets/calendar-grid/ui/CalendarGrid.tsx` (шапка дней недели — через
   `getWeekdayLabels()`, не `format()`)
10. Данные о выбранном языке нигде не хранятся на сервере — в приложении
    нет авторизации/аккаунта пользователя, поэтому язык — чисто
    браузерная настройка (`localStorage`), не синхронизируется между
    устройствами

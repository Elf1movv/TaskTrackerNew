# Наследие Figma Make

Три файла в этой папке — то, что осталось от исходной генерации проекта
инструментом **Figma Make** (см. корневой `README.md`, `ATTRIBUTIONS.md`).
Реальному приложению они не нужны и никуда не импортируются — подробное
объяснение каждого файла в `docs/FILE_GUIDE.md`, раздел 5.

Собраны сюда одной папкой, чтобы не путаться с активными файлами
проекта в корне репозитория — раньше лежали вперемешку. Ничего не
удалено, только перенесено.

- `guidelines/Guidelines.md` — незаполненный шаблон Figma Make для
  инструкций дизайн-системы.
- `pnpm-workspace.yaml` — конфиг для `pnpm`, но проект использует `npm`.
- `default_shadcn_theme.css` — дефолтная тема shadcn/ui для справки;
  реальная тема — `src/styles/theme.css`.
